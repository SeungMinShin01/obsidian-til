# JAVA 연산자 심화

> 상위: [[JAVA 기본 문법]]

## 비트 연산 ※

```java
int a = 12;
int b = 10;

int and = a & b;
int or  = a | b;
int xor = a ^ b;
int left  = a << 1;
int right = a >> 1;
```

- 2진수 자리끼리 연산한다: `&`(둘 다 1), `|`(하나라도 1), `^`(다르면 1), `~`(반전)
- 시프트는 곱셈·나눗셈의 빠른 버전이다: `<< 1`은 ×2, `>> 1`은 ÷2
- 실전 활용: 홀수 판별 `(n & 1) == 1`, 이진탐색 중간값 `(a + b) >>> 1`(오버플로 방지)
- 정보처리기사의 서브넷 마스크 AND 연산이 정확히 이것이다

## 조건문에서 & vs && 

```java
if (a() & b()) { }
if (a() && b()) { }
```

- `&`는 단축 평가가 없어 양쪽을 다 실행한다. 조건문에서는 항상 `&&` `||`를 쓰고, `&` `|`는 비트 연산용으로만 남긴다

## compareTo — 문자열·객체의 대소 비교 ※

```java
"apple".compareTo("banana");
if (s1.compareTo(s2) > 0) { }
```

- 문자열엔 `>` `<`를 못 쓴다. `compareTo`가 사전순으로 앞이면 음수, 같으면 0, 뒤면 양수를 준다
- 정렬(Comparator)의 기반이라, "정렬 기준을 직접 정한다"는 코드가 결국 compareTo를 만드는 일이다

## 복합 대입의 숨은 캐스팅

```java
byte b = 10;
b += 5;
```

- `b = b + 5;`는 int가 되어 컴파일 에러지만 `b += 5;`는 통과한다. `+=` 안에 `(byte)` 캐스팅이 숨어 있기 때문이다
- 편하지만 값이 조용히 잘릴 수 있다는 뜻이기도 하다

## 오버플로 ※

```java
int big = 2_000_000_000;
int sum = big + big;
long ok = (long) big + big;
```

- int 최대(약 21억)를 넘으면 에러 없이 음수로 넘어간다(오버플로). 큰 수 계산은 계산 **전에** long으로 캐스팅한다
- 숫자 리터럴의 `_`는 자릿수 구분용이고 값에 영향이 없다
