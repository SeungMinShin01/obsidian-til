# 피그마 메모 (이관)

> 노션 `Velog > day02` 페이지 하단의 토글 블록에 있던 메모입니다.

## 원본 내용

```
피그마
  Page = Sheet
```

피그마의 **Page**가 엑셀/스프레드시트의 **Sheet**와 같은 개념이라는 메모입니다. 하나의 파일 안에 여러 페이지를 두고 화면·플로우별로 나눠 작업합니다.

## 보충

### 피그마 구조

```
Team
└── Project
    └── File
        └── Page  (= 스프레드시트의 Sheet)
            └── Frame  (= 화면 하나, 아트보드)
                └── Group / Component / Layer
```

### 프론트엔드 개발자가 알면 좋은 기능

| 기능 | 용도 |
|---|---|
| **Inspect(개발자 모드)** | 요소를 클릭하면 CSS 코드가 바로 나옵니다 |
| **Auto Layout** | flexbox와 개념이 같습니다 (direction, gap, padding, align) |
| **Constraints** | 부모 크기가 변할 때의 동작 = 반응형 |
| **Component / Variant** | 재사용 컴포넌트. React 컴포넌트와 1:1 대응 |
| **Styles** | 색상·폰트를 변수로 등록 = CSS 변수 |
| **Export** | `@1x`, `@2x`, SVG, WebP 내보내기 |

**Auto Layout ↔ CSS Flexbox 대응**

| 피그마 | CSS |
|---|---|
| Direction: Horizontal | `flex-direction: row` |
| Direction: Vertical | `flex-direction: column` |
| Gap | `gap` |
| Padding | `padding` |
| Alignment | `justify-content` + `align-items` |
| Fill container | `flex: 1` |
| Hug contents | `width: fit-content` |

CSS flexbox를 알면 피그마 Auto Layout이 바로 이해되고, 반대도 마찬가지입니다. `day08`에서 flex 10패턴을 실험한 게 여기서도 그대로 쓰입니다.

### 디자인 → 코드 흐름

1. 피그마에서 Frame 선택 → Inspect 패널
2. 색상·폰트·간격 수치를 그대로 CSS로 옮김
3. Auto Layout 구조 = flex 구조로 옮김
4. 이미지는 Export로 내보내기 (WebP 권장)

`day11/practice/practiceCSS8`(예약 사이트), `day14/practice/index`(쇼핑몰) 같은 페이지를 만들 때 피그마로 먼저 그려보면 CSS 작성 시간이 크게 줄어듭니다.
