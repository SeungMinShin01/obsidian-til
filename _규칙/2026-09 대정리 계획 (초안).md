# 2026-09 대정리 계획 (초안)

> 마스터 세션 작성. 사용자 "반영해줘" 전까지는 초안 — 기존 규칙을 바꾸지 않는다.
> 목적: 규칙을 한 벌로 확정하고, 구역별 정리를 각 세션에 분배할 수 있는 상태를 만든다.

## A. 원칙 (전 구역 공통)

1. **진실 한 벌** — 원본은 옵시디언 Vault 하나. 노션·깃허브·RAG 인덱스는 전부 자동 생성되는 파생 뷰이며, 파생본을 사람이 수정하지 않는다
2. **트리 = 주소, 인덱스 = 보조** — 도달 경로는 하나로 고정(트리·리스트), 찾기는 MOC(시간)·개념 노드(주제)·태그·전문 검색(키워드)이 담당. 그물은 인덱스 층에만
3. **경계는 이름에 새긴다** — 파일명 접두사·폴더·태그가 곧 필터. "구역명 치면 그 구역만 나온다"
4. **승격 3층 분리** — 발화는 사람의 직관("가로로 잇고 싶다"), 판정은 기계적 조건(2곳+ 등장), 형태는 제약(개념 노드는 별 모양 허용, 개념끼리 연결 금지)
5. **사람용 링크는 보수적으로, 기계용 연결은 검색이 대신한다** — 구역 간 링크는 억지로 늘리지 않는다. RAG(11월)가 링크 없이도 구역을 가로질러 회수한다
