# Python day02 — 리스트 선언과 인덱싱·슬라이싱

> 실습 파일: `day02/c4-1.py`
> 허브: [[Python 정리본 인덱스]] · 이전: [[Python day01 비교·논리 연산자와 if 조건문]] · 다음: (아직 없음)

파이썬 수업 둘째 날은 교재 4장, **리스트**로 시작했다. 첫날 문자열에 썼던 대괄호 인덱싱과 슬라이싱이 리스트에도 **똑같은 모양으로** 적용된다는 것이 이 파일의 핵심이다. 리스트 하나를 선언해서 인덱스로 요소를 꺼내고, 구간을 잘라 내고, 요소 값을 바꾸고, 음수 인덱스로 뒤에서 세고, 리스트 안의 문자열에 다시 대괄호를 붙여 글자 하나를 꺼내는 데까지 갔다. 자바 배열과 가장 다른 점은 **자료형이 섞여도 되고 길이가 고정되지 않는다**는 것이라, 그 차이를 중심으로 적어 둔다.

## 1. 배운 내용

### 1-1. 리스트란 — 대괄호에 쉼표로 나열한 요소의 모음

```python
# 리스트란? 대괄호 [ ] 에 자료를 쉼표로 구분하여 여러 자료들을 저장
# [ 요소, 요소, 요소 ] , 요소 = element
# 인덱스란? 리스트 내 요소들이 저장된 순서 번호, 0번 시작 ~
list_a = [ 273, 32, 103, "문자열", True, False ]   # 리스트 선언
```

| 용어 | 뜻 |
| --- | --- |
| 리스트(list) | 대괄호 `[ ]` 안에 값을 쉼표로 나열한 **순서 있는 모음**. `type()`으로 찍으면 `<class 'list'>` |
| 요소(element) | 리스트 안에 들어 있는 값 하나하나 |
| 인덱스(index) | 요소가 저장된 순서 번호. **0부터** 시작한다 |

자바의 배열(`int[] arr = {273, 32, 103};`)과 비교하면 모양은 비슷하지만 성격이 다르다. 자바 배열은 선언할 때 자료형을 하나로 정하고 길이도 고정되지만, 파이썬 리스트는 위처럼 **정수·문자열·불리언을 한 리스트에 섞어** 넣을 수 있고, 뒤에서 요소를 더하거나 빼서 길이가 변한다. 자바로 치면 `ArrayList<Object>`에 가깝다. 변수명을 `list_a`처럼 쓴 이유도 적어 둘 만하다 — `list`는 파이썬의 내장 함수 이름이라 변수명으로 덮어쓰면 그 뒤로 `list()`를 못 쓰게 되므로 피하는 편이 안전하다.

### 1-2. 인덱싱 — 요소 하나 꺼내기

```python
print( list_a[ 2 ] )    # 103
```

| 식 | 결과 | 설명 |
| --- | --- | --- |
| `list_a[0]` | `273` | 첫 번째 요소 |
| `list_a[2]` | `103` | 세 번째 요소 — 인덱스는 0부터이므로 2 |
| `list_a[6]` | `IndexError` | 요소가 6개라 마지막 인덱스는 5. 범위를 넘으면 오류 |

문자열에서 `s[2]`로 글자 하나를 꺼냈던 것과 같은 문법이다. 자바의 `arr[2]`와도 똑같고, 범위를 넘으면 자바의 `ArrayIndexOutOfBoundsException`처럼 `IndexError: list index out of range`가 난다. 인덱스 자리에는 정수만 올 수 있다 — `list_a[1.0]`처럼 실수를 넣으면 `TypeError`다.

### 1-3. 슬라이싱 — 구간 잘라 내기

```python
print( list_a[ 1:3 ] )  # [32, 103]  — 인덱스 1부터 3 앞까지
```

| 식 | 결과 | 설명 |
| --- | --- | --- |
| `list_a[1:3]` | `[32, 103]` | 1번부터 **3번 앞(2번)까지**. 끝 인덱스는 포함하지 않는다 |
| `list_a[:2]` | `[273, 32]` | 시작을 비우면 처음부터 |
| `list_a[3:]` | `["문자열", True, False]` | 끝을 비우면 마지막까지 |
| `list_a[1:100]` | `[32, 103, "문자열", True, False]` | 범위를 넘겨도 오류 없이 있는 만큼만 |

문자열 슬라이싱의 규칙이 그대로다. "끝 − 시작 = 요소 개수"라서 `[1:3]`은 두 개다. 결과가 **새 리스트**로 돌아온다는 점이 중요하다. 원본 `list_a`는 그대로이고, 잘라 낸 복사본이 하나 더 생긴다. 자바에서는 `Arrays.copyOfRange(arr, 1, 3)`이나 `list.subList(1, 3)`을 불러야 하던 일이 대괄호 하나로 끝난다.

### 1-4. 요소 값 바꾸기

```python
list_a[2] = 7          # 요소 값 수정 / 변경
print( list_a[2] )     # 7
```

인덱스로 자리를 지목하고 `=`로 새 값을 넣으면 그 자리가 바뀐다. 리스트 전체를 다시 만드는 것이 아니라 **그 자리 하나만** 교체된다. 첫날 노트에서 문자열은 `s[0] = "하"`가 `TypeError`를 냈는데(문자열은 불변), 리스트는 이것이 된다. 같은 대괄호 문법을 쓰면서도 **문자열은 불변, 리스트는 가변**이라는 차이가 여기서 처음 드러난다. 바꾸는 값의 자료형이 원래 값과 달라도 상관없다 — `103`이 있던 자리에 `"칠"`을 넣어도 오류가 없다.

### 1-5. 음수 인덱스 — 뒤에서 세기

```python
print( list_a[-2] )    # True  — 뒤에서 두 번째
```

| 앞에서 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 요소 | `273` | `32` | `7` | `"문자열"` | `True` | `False` |
| 뒤에서 | -6 | -5 | -4 | -3 | -2 | -1 |

`-1`이 마지막 요소, `-2`가 그 앞이다. 자바에는 없는 기능이라 자바라면 `arr[arr.length - 2]`로 써야 하던 것이 `[-2]`로 줄어든다. 슬라이싱에도 그대로 써서 `list_a[-2:]`는 마지막 두 개, `list_a[:-1]`은 마지막 하나를 뺀 나머지다. 앞 표의 `-0`은 없다 — `list_a[-0]`은 그냥 `list_a[0]`이다.

### 1-6. 요소가 문자열이면 한 번 더 인덱싱할 수 있다

```python
print( list_a[3][1] )   # "자"  — 3번 요소 "문자열"의 1번 글자
# print( list_a[1][1] ) # 오류 — 1번 요소 32 는 정수라 인덱싱이 안 된다
```

`list_a[3]`은 `"문자열"`이고, 문자열은 첫날 배운 대로 인덱싱이 되므로 뒤에 `[1]`을 하나 더 붙이면 두 번째 글자 `"자"`가 나온다. 대괄호를 **왼쪽부터 차례로** 적용한다고 읽으면 된다. 반면 정수 요소에 대괄호를 붙이면 `TypeError: 'int' object is not subscriptable`이 난다 — 대괄호 인덱싱은 문자열·리스트처럼 **순서가 있는 값**에만 된다는 뜻이다. 리스트 안에 리스트를 넣으면(`[ [1, 2], [3, 4] ]`처럼) 같은 방식으로 `[0][1]`처럼 꺼내게 되는데, 이것이 자바 2차원 배열에 해당한다.

## 2. 추가로 알면 좋은 활용법

### 2-1. `len`·`in`·`+`·`*` — 문자열에서 쓰던 연산이 리스트에도 된다

```python
print( len(list_a) )          # 6
print( 103 in list_a )        # True / False — 요소 포함 여부
print( [1, 2] + [3] )         # [1, 2, 3] — 이어 붙이기 (새 리스트)
print( [0] * 3 )              # [0, 0, 0] — 반복
```

첫날 문자열에 썼던 `len`·`in`·`+`·`*`가 리스트에서도 같은 뜻으로 동작한다. 파이썬은 문자열·리스트·튜플을 모두 **시퀀스**라는 한 묶음으로 보기 때문에, 한 번 익힌 문법이 다른 자료형에서도 재사용된다. 특히 `in`은 `if 103 in list_a:`처럼 조건문 안에서 "이 값이 있나"를 물을 때 자주 쓴다. `[0] * 3`은 같은 값으로 채운 리스트를 빠르게 만들 때 쓰는 관용구다.

### 2-2. 요소 더하고 빼기 — `append`·`insert`·`remove`·`pop`·`del`

```python
list_a.append(500)       # 맨 뒤에 추가          → [..., False, 500]
list_a.insert(0, -1)     # 0번 자리에 끼워 넣기   → [-1, 273, ...]
list_a.remove(32)        # 값 32 를 찾아 하나 삭제
last = list_a.pop()      # 마지막 요소를 꺼내면서 삭제 (반환값 있음)
del list_a[0]            # 인덱스로 삭제
```

| 메소드 | 하는 일 | 자바 `ArrayList` |
| --- | --- | --- |
| `append(x)` | 맨 뒤에 추가 | `add(x)` |
| `insert(i, x)` | `i`번 자리에 끼워 넣기 | `add(i, x)` |
| `remove(x)` | **값** `x`를 찾아 첫 번째 것 삭제. 없으면 `ValueError` | `remove(Object)` |
| `pop(i)` | `i`번 요소를 돌려주면서 삭제. 비우면 마지막 | `remove(int)` |
| `del lst[i]` | 인덱스로 삭제. 슬라이스(`del lst[1:3]`)도 된다 | — |

수업 파일은 아직 선언·조회·수정까지만 다뤘지만, 리스트가 자바 배열과 다른 핵심이 바로 **길이가 변한다**는 점이라 같이 적어 둔다. 자바에서는 배열 크기를 늘리려면 새 배열을 만들어 복사해야 했지만 파이썬은 `append` 한 줄이다. `remove`는 값으로, `pop`·`del`은 인덱스로 지운다는 구분만 기억하면 된다.

### 2-3. 슬라이싱 세 번째 칸과 역순

```python
nums = [0, 1, 2, 3, 4, 5]
print( nums[::2] )    # [0, 2, 4] — 두 칸씩
print( nums[::-1] )   # [5, 4, 3, 2, 1, 0] — 뒤집기
print( nums[1:5:2] )  # [1, 3]
```

`[시작:끝:간격]`의 세 번째 칸은 문자열 노트에서 적어 둔 것과 동일하다. 간격을 `-1`로 주면 뒤집힌 **새 리스트**가 돌아오고, 원본을 그 자리에서 뒤집고 싶으면 `nums.reverse()`를 쓴다. 정렬도 같은 짝이다 — `sorted(nums)`는 새 리스트, `nums.sort()`는 원본 변경.

### 2-4. 슬라이스에 대입하기

```python
nums = [0, 1, 2, 3, 4]
nums[1:3] = [10, 20, 30]    # [0, 10, 20, 30, 3, 4] — 구간을 통째로 교체, 길이도 바뀐다
```

1-4의 "한 자리 바꾸기"를 구간으로 넓힌 것이다. 왼쪽 슬라이스 길이와 오른쪽 리스트 길이가 달라도 되고, 그만큼 리스트가 늘거나 준다. 자바에는 대응하는 문법이 없고 반복문을 돌려야 하던 일이다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 리스트는 참조로 다뤄진다 — 복사와 별명

```python
a = [1, 2, 3]
b = a            # 별명 — 같은 리스트를 가리킨다
b[0] = 99
print(a)         # [99, 2, 3]  — a 도 바뀐다

c = a[:]         # 슬라이싱으로 복사 — 새 리스트
c[0] = 0
print(a)         # [99, 2, 3]  — a 는 그대로
```

`b = a`는 리스트를 복사하는 것이 아니라 **같은 객체에 이름을 하나 더 붙이는** 것이다. 자바에서 배열 변수를 다른 변수에 대입하면 같은 배열을 가리키는 것과 같은 원리다. 복사본이 필요하면 `a[:]`·`a.copy()`·`list(a)` 중 하나를 쓴다. 리스트가 가변이라서 생기는 문제이고, 문자열은 불변이라 이런 걱정이 없다 — 1-4에서 본 "문자열은 불변, 리스트는 가변"이 실제로 영향을 주는 자리가 여기다. 리스트 안에 리스트가 들어 있으면 `[:]`도 바깥 껍데기만 복사하므로(얕은 복사), 안쪽까지 떼어 내려면 `copy.deepcopy`가 필요하다 — 이 폴더의 Python 코드 해석 문제(이관) 노트에 있는 얕은 복사 문제가 바로 이 이야기다.

### 3-2. 튜플 — 바꿀 수 없는 리스트

`(273, 32, 103)`처럼 소괄호로 만들면 **튜플**이고, 인덱싱·슬라이싱·`len`·`in`은 리스트와 똑같이 되지만 `t[0] = 1`처럼 요소를 바꾸는 것은 `TypeError`다. 바뀌면 안 되는 값 묶음(좌표, 설정값, 함수가 여러 값을 돌려줄 때)에 쓴다. 리스트가 "문자열처럼 인덱싱되는데 바꿀 수 있는 것"이라면, 튜플은 "리스트처럼 생겼는데 문자열처럼 못 바꾸는 것"으로 묶어 두면 정리가 된다.

### 3-3. 리스트를 돌리는 `for`와 `enumerate`

```python
for item in list_a:                 # 요소를 하나씩
    print(item)
for i, item in enumerate(list_a):   # 인덱스와 요소를 같이
    print(i, item)
```

리스트를 손에 넣었으니 다음은 당연히 반복문이다. 자바의 향상된 `for`(`for (Object x : list)`)에 해당하는 것이 `for item in list_a:`이고, 인덱스까지 필요하면 `range(len(list_a))`보다 `enumerate`가 관용구다. 수업 진도상 다음 교재 절이 이쪽이 될 가능성이 높아 미리 적어 둔다.
