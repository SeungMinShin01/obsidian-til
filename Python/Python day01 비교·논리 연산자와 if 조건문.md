# Python day01 — 비교·논리 연산자와 if 조건문

> 실습 파일: `day01/c3-1.py`
> 허브: [[Python 정리본 인덱스]] · 이전: [[Python day01 파이썬 시작과 키워드 확인]] · 다음: (아직 없음)

같은 날 교재 3장으로 넘어가면서 파일이 `c3-1.py`로 바뀌었다. 2장까지가 값을 만들고 찍는 이야기였다면 여기서부터는 **흐름을 가르는** 이야기다. 비교 연산자로 `True`/`False`를 만들고, 논리 연산자로 그 값을 묶고, `if`·`elif`·`else`로 어느 블록을 실행할지 고른다. 자바와 모양이 거의 같지만 중괄호 대신 **콜론과 들여쓰기**가 블록을 정한다는 점, `&&`·`||`·`!` 대신 **영어 단어**를 쓴다는 점, 그리고 `10 < x < 30`처럼 비교를 이어 쓸 수 있다는 점이 눈에 띄는 차이라 따로 적어 둔다.

## 1. 배운 내용

### 1-1. 비교 연산자와 범위 비교

```python
# 비교연산자 : == , != , > , < , >= , <=
x = 25
print(10 < x < 30)   # True — 범위 비교를 한 식으로
```

| 연산자 | 뜻 | 결과 |
| --- | --- | --- |
| `==` | 같다 | `bool` |
| `!=` | 다르다 | `bool` |
| `>` `<` `>=` `<=` | 크다·작다·크거나 같다·작거나 같다 | `bool` |
| `a < x < b` | `a < x and x < b`를 줄인 것 | `bool` |

비교의 결과는 언제나 `True` 아니면 `False`이고, `type()`으로 찍으면 `<class 'bool'>`이 나온다. 자바와 가장 다른 지점이 마지막 줄이다. 자바에서는 `10 < x && x < 30`으로 두 번 비교해 묶어야 하지만, 파이썬은 수학 부등식처럼 **`10 < x < 30`** 한 줄로 쓴다. 가운데 `x`는 한 번만 계산되고, 왼쪽 비교가 `False`면 오른쪽은 보지 않는다. `a <= x <= b`, `a < x <= b`처럼 섞어 써도 되고 세 개 이상 이어도 된다.

### 1-2. 논리 연산자 — `not`·`and`·`or`

```python
print( not True )         # False
print( True and True )    # True
print( True and False )   # False
print( True or False )    # True
```

| 파이썬 | 자바 | 뜻 |
| --- | --- | --- |
| `not a` | `!a` | 뒤집기 |
| `a and b` | `a && b` | 둘 다 참일 때만 참 |
| `a or b` | `a \|\| b` | 하나라도 참이면 참 |

기호가 아니라 **영어 단어**가 연산자다. 셋 다 1장에서 본 키워드 목록(`keyword.kwlist`)에 들어 있어서 변수명으로는 못 쓴다. 우선순위는 `not` → `and` → `or` 순이고, 비교 연산자가 논리 연산자보다 먼저 계산되므로 `age >= 19 and age < 65`처럼 괄호 없이 써도 뜻이 통한다. 다만 `not`은 바로 뒤의 값 하나에만 붙으므로 `not a == b`는 `not (a == b)`로 읽힌다 — 헷갈리면 괄호를 치는 편이 안전하다. 자바처럼 **단락 평가**도 된다. `and`는 왼쪽이 `False`면 오른쪽을 보지 않고, `or`는 왼쪽이 `True`면 오른쪽을 보지 않는다.

### 1-3. `if` ~ `else`

```python
# if 조건식:
#     (들여쓰기) 참이면
# else :
#     (들여쓰기) 거짓이면
age = 10
if age >= 19 :
    print('성인입니다')
else :
    print('미성년자입니다')
```

| 자리 | 설명 |
| --- | --- |
| `if 조건식:` | 조건식 뒤에 **콜론**. 괄호는 없어도 된다 |
| 들여쓰기 | 콜론 다음 줄부터 **같은 깊이로 들여쓴 줄**이 그 블록이다. 자바의 `{ }` 역할 |
| `else:` | `if`와 **같은 깊이**에 두고 역시 콜론으로 끝낸다 |

자바와 견주면 `if (age >= 19) { ... } else { ... }`에서 괄호와 중괄호가 사라지고 콜론과 들여쓰기가 들어온 모양이다. 핵심은 **들여쓰기가 문법**이라는 점이다. 자바에서는 들여쓰기가 어긋나도 중괄호만 맞으면 돌아갔지만, 파이썬은 들여쓰기가 다르면 `IndentationError`가 나거나 블록 밖으로 빠져 버린다. 수업 파일 주석처럼 탭 한 번(VS Code에서는 보통 공백 4칸으로 바뀐다)이 한 단계이고, 한 파일 안에서는 탭과 공백을 섞지 않는 편이 안전하다. 블록이 끝나는 자리는 닫는 괄호가 아니라 **들여쓰기가 원래 깊이로 돌아오는 줄**이다.

### 1-4. `if` ~ `elif` ~ `else`

```python
point = 85
if point >= 90:
    print('A')
elif point >= 80:
    print('B')
elif point >= 70 :
    print('C')
else :
    print('재시험')
```

| 자리 | 설명 |
| --- | --- |
| `elif 조건식:` | 자바의 `else if`. 앞 조건이 거짓일 때만 검사한다 |
| 검사 순서 | 위에서부터 하나씩 보고 **처음 참인 블록 하나만** 실행한 뒤 전체를 빠져나온다 |
| `else:` | 어느 조건에도 안 걸렸을 때. 생략할 수 있다 |

`point = 85`는 `>= 90`에서 거짓, `>= 80`에서 참이라 `B`가 찍히고 그 아래 `>= 70`은 보지도 않는다. 그래서 조건은 **좁은 것(큰 값)부터 넓은 것 순서**로 적어야 한다. `>= 70`을 맨 위에 두면 85도 90도 전부 `C`가 된다. 자바의 `else if`를 한 단어로 붙인 `elif`가 철자 그대로 키워드라, `else if`로 쓰면 `else` 뒤에 콜론이 없다는 `SyntaxError`가 난다.

## 2. 추가로 알면 좋은 활용법

### 2-1. 조건식에 `bool`이 아닌 값이 와도 된다 — 참·거짓 판정

```python
name = input("이름>")
if name:                 # 빈 문자열이면 거짓
    print("안녕,", name)
else:
    print("이름이 비었다")

items = []
if not items:            # 빈 리스트면 거짓
    print("비어 있음")
```

| 거짓으로 취급 | 참으로 취급 |
| --- | --- |
| `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()` | 그 밖의 모든 값 |

자바는 `if` 안에 `boolean`만 올 수 있지만 파이썬은 아무 값이나 올 수 있고, **비어 있거나 0이면 거짓** 으로 본다. 그래서 `if len(items) > 0:` 대신 `if items:`, `if name != "":` 대신 `if name:`으로 줄여 쓰는 것이 관용구다. `input()`이 돌려주는 빈 문자열 검사에 특히 자주 쓴다.

### 2-2. `in`과 `is`도 조건식의 단골

```python
grade = "B"
if grade in ("A", "B"):          # 여러 값 중 하나인지 — == 를 or 로 잇는 대신
    print("합격")

value = None
if value is None:                # None 비교는 == 가 아니라 is
    print("값 없음")

if "안녕" in "안녕하세요":         # 문자열 포함 여부 (앞 노트의 in 이 그대로 조건식이 된다)
    print("포함")
```

`grade == "A" or grade == "B"`는 `grade in ("A", "B")`로 줄어든다. `None`인지 확인할 때는 `== None`도 동작은 하지만 `is None`이 관용구다 — `None`은 프로그램 안에 하나뿐이라 "같은 객체인가"를 묻는 `is`가 더 정확하고 빠르다. `in`과 `is`도 `and`·`or`·`not`처럼 키워드 목록에 들어 있는 단어다.

### 2-3. 조건부 표현식과 한 줄 `if`

```python
age = 10
status = "성인" if age >= 19 else "미성년자"    # 자바의  age >= 19 ? "성인" : "미성년자"
print(status)

if age >= 19: print("성인")                      # 블록이 한 줄이면 같은 줄에 붙여도 된다 (권장하진 않음)
```

자바의 삼항 연산자 `조건 ? a : b`가 파이썬에서는 **`a if 조건 else b`** 순서로 바뀐다. 참일 때 값이 먼저 오고 조건이 가운데 들어간다는 점만 익혀 두면 된다. 값 하나를 조건에 따라 고를 때 `if`·`else` 네 줄을 한 줄로 줄여 준다.

### 2-4. 중첩 `if`와 `pass`

```python
if age >= 19:
    if point >= 80:
        print("성인이고 80점 이상")
    else:
        print("성인이지만 80점 미만")
else:
    pass            # 아직 할 일이 없을 때 자리만 잡아 두는 문장
```

블록 안에 블록을 두면 들여쓰기가 한 단계 더 깊어진다. 빈 블록은 허용되지 않아서(콜론 뒤에 아무것도 없으면 `IndentationError`) 나중에 채울 자리에는 `pass`를 넣어 둔다. 중첩이 세 단계를 넘기면 읽기 어려워지므로, `age >= 19 and point >= 80`처럼 조건을 `and`로 합치거나 먼저 걸러 내는 `if`를 앞에 두는 편이 안전하다.

## 3. 더 나아가 알면 좋은 것

### 3-1. `and`·`or`는 `bool`이 아니라 값을 돌려준다

`True and "hello"`를 찍어 보면 `True`가 아니라 `"hello"`가 나온다. `and`는 왼쪽이 거짓이면 왼쪽 값을, 아니면 오른쪽 값을 그대로 돌려주고, `or`는 왼쪽이 참이면 왼쪽 값을, 아니면 오른쪽 값을 돌려준다. `if` 안에서는 어차피 참·거짓으로 판정되니 상관없지만, `name = input("이름>") or "익명"`처럼 **기본값을 채우는 관용구**가 여기서 나온다. 자바의 `&&`·`||`가 항상 `boolean`을 돌려주는 것과 다른 점이다.

### 3-2. `match` ~ `case`

자바의 `switch`에 해당하는 문법이 파이썬 3.10부터 `match`·`case`로 들어왔다. `elif`가 길게 이어질 때 값·패턴별로 가지를 나누는 용도이고, 1장 노트에서 본 소프트 키워드(`keyword.softkwlist`)가 바로 이 `match`·`case`다. 단순 값 비교는 `elif`로 충분하고, 리스트·딕셔너리 모양까지 뜯어 맞추는 **구조 패턴 매칭**이 필요할 때 꺼내 보면 된다.

### 3-3. 들여쓰기 규칙과 PEP 8

들여쓰기가 문법이라 스타일이 곧 동작이다. 파이썬 공식 스타일 가이드(PEP 8)는 **공백 4칸**을 권하고, 탭과 공백을 섞으면 파이썬 3에서는 아예 `TabError`가 난다. VS Code는 `.py` 파일에서 Tab 키를 누르면 공백 4칸으로 바꿔 주므로 보통 신경 쓸 일은 없지만, 다른 곳에서 복사해 온 코드가 이상하게 오류를 낼 때는 이 문제인지 먼저 의심해 보면 된다. 편집기 하단의 "Spaces: 4" 표시가 그 설정이다.
