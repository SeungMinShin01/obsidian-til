# Python day07 — 넘파이 통계 함수와 axis

> 실습 파일: `day07/n-04.py`
> 허브: [[Python 정리본 인덱스]] · 이전: [[Python day07 넘파이 배열 병합·정렬과 조건 필터링]] · 다음: [[Python day07 넘파이로 고객 구매 데이터 분석 실습]]

배열을 붙이고 거르는 법까지 봤으니 이번에는 **배열을 숫자 몇 개로 요약하는** 통계 함수다. 최솟값·최댓값과 그 위치, 합계·평균·중앙값, 분산·표준편차, 제곱근까지 1차원에서 한 번 돌리고, 같은 함수를 2차원에 `axis`를 붙여 다시 돌렸다. 짧은 파일인데 이 시간의 핵심은 함수 이름이 아니라 **`axis=0`이 열마다, `axis=1`이 행마다**라는 한 줄과, 분산·표준편차가 무엇을 재는 수치인지 주석으로 적어 둔 두 줄이다.

## 1. 배운 내용

### 1-1. 1차원 배열 통계 함수

```python
import numpy as np

x = np.array( [1,2,3,4,5] )
print(np.min(x) , np.max(x))         # 1 5          최솟값, 최댓값
print(np.argmin(x), np.argmax(x))    # 0 4          최솟값 위치, 최댓값 위치
print(np.sum(x), np.mean(x), np.median(x))  # 15 3.0 3.0   합계 평균 중앙값
print(np.var(x))    # 2.0          분산: 평균으로부터 요소 값들이 떨어진 정도
print(np.std(x))    # 1.414…       표준편차: 분산에 양의 제곱근 사용하여 데이터 단위 맞춘 값
print(np.sqrt(x))   # [1. 1.414 1.732 2. 2.236]  양의 제곱근(루트)
```

| 함수 | 결과 | 뜻 |
| --- | --- | --- |
| `np.min(x)` / `np.max(x)` | `1` / `5` | 가장 작은 값 / 가장 큰 값 |
| `np.argmin(x)` / `np.argmax(x)` | `0` / `4` | 그 값이 있는 **인덱스** |
| `np.sum(x)` | `15` | 합계 |
| `np.mean(x)` | `3.0` | 평균 — 합계 ÷ 개수 |
| `np.median(x)` | `3.0` | 중앙값 — 크기순으로 세웠을 때 가운데 값 |
| `np.var(x)` | `2.0` | 분산 — 각 값이 평균에서 떨어진 거리의 제곱의 평균 |
| `np.std(x)` | `1.4142…` | 표준편차 — 분산의 양의 제곱근 |
| `np.sqrt(x)` | 배열 | 요소마다 제곱근 — 통계가 아니라 요소 연산 |

`min`·`max`·`sum`은 day02에서 리스트에 쓰던 내장 함수와 이름이 같다. 차이는 `np.`가 붙은 쪽이 배열 전용으로 C 안에서 돌아가 훨씬 빠르고, `axis` 같은 옵션을 받는다는 점이다. 결과 자료형도 눈여겨볼 만하다. `np.sum`은 정수 배열에서 정수(`15`)를 주지만 `np.mean`·`np.median`은 나눗셈이 들어가므로 항상 실수(`3.0`)다.

### 1-2. `arg` 접두사 — 값이 아니라 위치

`np.argmax(x)`가 `4`를 돌려준 것은 "최댓값 5가 **4번 칸**에 있다"는 뜻이다. 지난 노트의 `argsort`와 같은 접두사로, **arg가 붙으면 값 대신 인덱스**라고 읽으면 된다. 쓸모는 "가장 큰 값이 **누구** 것인가"를 물을 때다. 매출 배열에서 `argmax`로 자리를 찾아 그 자리의 고객ID를 꺼내는 식이고, 바로 다음 연습문제에서 그렇게 쓴다.

2차원 배열에서는 주의할 점이 하나 있다.

```python
y = np.array([ [1,2,3] , [4,5,6]])
print( np.argmin(y) , np.argmax(y))   # 0 5
```

`axis`를 주지 않으면 2차원 배열을 **일렬로 편 상태의 인덱스**를 돌려준다. `6`은 1행 2열인데 결과는 `(1, 2)`가 아니라 `5`다. 행·열 좌표가 필요하면 `np.unravel_index(5, y.shape)`로 `(1, 2)`를 받거나, `axis`를 줘서 행·열마다 따로 묻는다.

### 1-3. 분산과 표준편차 — "흩어진 정도"를 재는 두 수

주석에 적어 둔 정의를 식으로 풀면 이렇다.

```
평균      m  = (1+2+3+4+5) / 5 = 3
편차      x - m = [-2, -1, 0, 1, 2]
분산      var = ((-2)² + (-1)² + 0² + 1² + 2²) / 5 = 10 / 5 = 2.0
표준편차  std = √2 = 1.414…
```

| | 분산 `var` | 표준편차 `std` |
| --- | --- | --- |
| 구하는 법 | 편차(값 − 평균)를 **제곱**해서 평균 | 분산에 **양의 제곱근** |
| 단위 | 원래 단위의 **제곱** (원² · 분²) | 원래 단위 **그대로** (원 · 분) |
| 읽는 법 | 수치 자체는 직관이 어렵다 | "평균에서 보통 이만큼 떨어져 있다" |

편차를 그냥 평균하면 양수·음수가 상쇄되어 항상 0이 되기 때문에 제곱해서 더한다. 그 대신 단위가 제곱이 되어 버리므로 다시 루트를 씌워 단위를 되돌린 것이 표준편차다 — 주석의 "데이터 단위 맞춘 값"이 이 뜻이다. 그래서 실제로 읽을 때는 표준편차를 본다. 평균 3에 표준편차 1.4면 "대략 1.6~4.4 사이에 값들이 몰려 있다"고 감을 잡을 수 있다. `np.sqrt`가 통계 함수 사이에 끼어 있는 것도 이 때문인데, `np.sqrt(np.var(x))`가 `np.std(x)`와 같다는 걸 확인하는 재료다.

### 1-4. 2차원 배열에서 `axis`로 방향 정하기

```python
y = np.array([ [1,2,3] , [4,5,6]])
print(np.min(y) , np.max(y))                # 1 6         전체에서
print(np.min(y, axis=0) , np.max(y, axis=1)) # [1 2 3] [3 6]   axis=0 열마다 / axis=1 행마다
print( np.sum(y, axis=0) , np.mean(y, axis=0) , np.median(y, axis=1) )
# [5 7 9]  [2.5 3.5 4.5]  [2. 5.]
```

| 호출 | 결과 | 읽는 법 |
| --- | --- | --- |
| `np.min(y)` | `1` | `axis` 없음 — 2차원 전체를 하나로 요약 |
| `np.min(y, axis=0)` | `[1 2 3]` | **열마다** 최솟값 — 1열 `[1,4]`→1, 2열 `[2,5]`→2, 3열 `[3,6]`→3 |
| `np.max(y, axis=1)` | `[3 6]` | **행마다** 최댓값 — 0행 `[1,2,3]`→3, 1행 `[4,5,6]`→6 |
| `np.sum(y, axis=0)` | `[5 7 9]` | 열마다 합 — 세로로 더함 |
| `np.mean(y, axis=0)` | `[2.5 3.5 4.5]` | 열마다 평균 |
| `np.median(y, axis=1)` | `[2. 5.]` | 행마다 중앙값 |

주석 그대로 **`axis=0`은 열마다, `axis=1`은 행마다**다. 왜 그렇게 되는지는 지난 노트의 `concatenate`와 같은 그림으로 이해할 수 있다. 0번 축은 행 번호가 바뀌는 방향(↓)이고, `axis=0`으로 집계한다는 것은 **그 방향으로 눌러서** 없애 버린다는 뜻이다. 세로로 누르면 행이 사라지고 열마다 값 하나씩 남는다. `axis=1`은 가로(→)로 눌러 열이 사라지고 행마다 하나씩 남는다.

```
        axis=1 →
axis=0  [[1 2 3]      axis=0 집계: 세로로 눌러 → [열1 열2 열3] 길이 = 열 개수
  ↓      [4 5 6]]     axis=1 집계: 가로로 눌러 → [행1 행2]     길이 = 행 개수
```

헷갈릴 때 쓰는 확인법은 **결과 길이**다. `axis=0`의 결과는 열 개수(3)만큼, `axis=1`의 결과는 행 개수(2)만큼 나온다. "`axis=0` = 열 방향"이라고 외우면 반대로 틀리기 쉬운데, "`axis=0` = 행 번호를 지우는 쪽 = **열마다** 하나"로 외우면 안 틀린다. 표 데이터에서는 거의 항상 `axis=0`을 쓴다 — 행이 레코드(고객 한 명)이고 열이 항목(방문·체류·금액)이라, "항목별 평균"은 세로로 눌러야 나오기 때문이다.

## 2. 추가로 알면 좋은 활용법

### 2-1. 함수형과 메소드형

```python
np.sum(x)   ==  x.sum()
np.mean(y, axis=0)  ==  y.mean(axis=0)
np.argmax(x)  ==  x.argmax()
```

이 시간의 함수들은 모두 `배열.메소드()` 형태로도 있다. 결과는 같고 취향 차이인데, 판다스로 넘어가면 `df.mean()`·`df['col'].max()`처럼 **메소드형**만 쓰게 되므로 지금부터 메소드형에도 손을 익혀 두는 편이 자연스럽다. `np.median`과 `np.sqrt`만은 메소드형이 없다.

### 2-2. 요약 통계를 한 줄에 — 설명 통계 묶음

```python
sales = np.array([2019, 1439, 774, 2473, 0])
print(f"개수 {sales.size}  합 {sales.sum():,}  평균 {sales.mean():,.1f}  중앙 {np.median(sales):,.0f}")
print(f"최소 {sales.min()}  최대 {sales.max()}  표준편차 {sales.std():,.1f}")
print(np.percentile(sales, [25, 50, 75]))   # 사분위수 — 50은 중앙값과 같다
```

데이터를 받으면 처음 하는 일이 이 요약이다. 평균과 중앙값이 많이 다르면(여기선 평균 1341 vs 중앙 1439) 한쪽으로 치우친 값이 있다는 신호다 — `0`처럼 극단적인 값이 평균을 끌어내린다. 그래서 금액·소득 같은 데이터는 평균만 보지 않고 중앙값과 나란히 본다. `np.percentile`로 사분위수까지 뽑으면 판다스의 `describe()`가 보여 주는 것과 같은 그림이 된다.

### 2-3. `ddof` — 분산의 분모

```python
x = np.array([1, 2, 3, 4, 5])
np.var(x)          # 2.0   — n(5)으로 나눔: 모분산
np.var(x, ddof=1)  # 2.5   — n-1(4)로 나눔: 표본분산
```

넘파이의 `var`·`std`는 기본으로 **n**으로 나눈다. 통계 교과서나 엑셀의 `STDEV`, 판다스의 `.std()`는 **n−1**로 나누는 표본 표준편차가 기본이라 같은 데이터에서 숫자가 다르게 나온다. "전체 데이터를 다 가지고 있다"면 n, "일부를 뽑아 전체를 추정한다"면 n−1이 맞고, 판다스와 숫자를 맞춰야 하면 `ddof=1`을 준다. 이 차이를 모르면 나중에 두 도구의 결과가 안 맞아서 한참 헤매게 된다.

### 2-4. 정규화 — 평균·표준편차·최소·최대의 조합

```python
z = (x - x.mean()) / x.std()                        # 표준화(z-score): 평균 0, 표준편차 1
mm = (x - x.min()) / (x.max() - x.min())            # Min-Max: 0~1 사이
```

이 시간의 함수들이 실제로 가장 많이 조합되는 자리다. 단위가 다른 열(방문 횟수 1~50, 금액 0~2740)을 같은 자리에 놓고 비교하거나 머신러닝 모델에 넣기 전에 **스케일을 맞추는** 공식이다. 둘 다 배열 ↔ 스칼라 연산이라 반복문 없이 한 줄이고, `axis=0`과 섞으면 `(data - data.mean(axis=0)) / data.std(axis=0)`로 2차원 표의 **열마다** 한 번에 표준화된다 — 열 개수만큼의 평균 벡터가 각 행에 브로드캐스팅되는 것이다. 바로 다음 연습문제의 Step 5가 Min-Max 공식이다.

### 2-5. 결측값이 섞여 있을 때

```python
a = np.array([1, 2, np.nan, 4])
np.mean(a)       # nan  — 하나라도 nan이면 결과가 nan
np.nanmean(a)    # 2.333… — nan을 빼고 계산
np.isnan(a).sum()  # 1  — nan 개수
```

CSV를 읽으면 빈 칸이 `nan`으로 들어오는 일이 흔하다. `nan`은 어떤 연산을 해도 `nan`이라 `mean`·`sum`이 통째로 `nan`이 되어 버린다. `nanmean`·`nansum`·`nanmax`처럼 `nan` 접두사가 붙은 짝 함수가 전부 있고, 먼저 `isnan`으로 몇 개인지 세어 보는 것이 순서다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 집계(reduction)와 `keepdims`

`sum`·`mean`·`max`처럼 축 하나를 없애는 연산을 넘파이에서는 **리덕션**이라 부른다. `axis=0`으로 집계하면 `(2, 3)`이 `(3,)`으로 차원이 하나 줄어드는데, `keepdims=True`를 주면 `(1, 3)`으로 축을 남긴다. 집계 결과를 원본에 다시 브로드캐스팅할 때(`y - y.mean(axis=1, keepdims=True)`처럼 행마다 평균 빼기) 모양이 어긋나지 않게 해 주는 옵션이다. `axis=(0, 1)`처럼 축을 여러 개 동시에 넘길 수도 있고, 3차원 이상에서는 `axis=-1`(마지막 축)이 자주 쓰인다.

### 3-2. `cumsum`·`diff`·`np.unique`·`bincount`

통계 함수 옆에 늘 함께 쓰이는 도구들이다. `np.cumsum`은 누적합(월별 매출 → 누적 매출), `np.diff`는 인접한 값의 차이(일별 잔고 → 일별 변화량), `np.unique(x, return_counts=True)`는 값별 등장 횟수(범주 데이터의 `value_counts`), `np.bincount`는 음이 아닌 정수의 빈도표다. day02에서 딕셔너리로 `counter[number] += 1`을 하며 세던 일이 `unique`·`bincount` 한 줄이 된다. 상관계수 `np.corrcoef`·공분산 `np.cov`는 "방문 횟수와 구매 금액이 같이 움직이나"를 숫자로 답하는 다음 단계다.

### 3-3. 판다스 `describe()`와 `groupby`로

이 시간의 함수 전부가 판다스에서 `df.describe()` 한 번으로 묶여 나온다 — 개수·평균·표준편차·최소·사분위·최대. 그리고 `axis`로 열마다 집계하던 것이 판다스에서는 **그룹별 집계** `df.groupby('지점')['매출'].mean()`으로 확장된다. 넘파이만으로 그룹별 평균을 내려면 그룹마다 불리언 마스크를 만들어 `mean`을 반복해야 하는데, 판다스는 그걸 한 줄로 해 준다. "`axis=0`은 열마다"를 몸에 익혀 둔 것이 `groupby`의 "그룹마다"로 그대로 이어진다.
