# Python day02 — range 함수와 for·while 반복문

> 실습 파일: `day02/c4-3.py`
> 허브: [[Python 정리본 인덱스]] · 이전: [[Python day02 리스트·반복문 연습문제 풀이]] · 다음: [[Python day02 집계 함수와 reversed·enumerate 이터레이터]]

리스트·딕셔너리를 `for`로 돌리는 것까지는 앞 노트에서 봤고, 이 파일은 **돌릴 자료가 없을 때 숫자를 만들어 도는 법**이다. 교재 4-3 "범위 자료형"에 해당하는 내용으로, `range()`가 정수를 순서대로 만들어 주는 세 가지 모양, 그것을 `for`에 물려 1부터 10까지·거꾸로·홀수만 찍는 법, 그리고 조건이 참인 동안 계속 도는 `while`까지가 전부다. 리스트 노트 끝에서 `range(len(...))`을 잠깐 본 적이 있는데, 여기서는 `range` 자체를 정면으로 다룬다. 자바에서 `for (int i = 0; i < 10; i++)`로 쓰던 자리를 파이썬이 어떻게 메우는지가 이 노트의 축이다.

## 1. 배운 내용

### 1-1. `range()`의 세 가지 모양

```python
# 1. range(끝값) — 시작값 생략 시 0부터
print(range(5))           # range(0, 5)
print(list(range(5)))     # [0, 1, 2, 3, 4]

# 2. range(시작값, 끝값) — 끝값은 포함하지 않는다
print(list(range(3, 6)))  # [3, 4, 5]

# 3. range(시작값, 끝값, 단계)
print(list(range(0, 10, 2)))  # [0, 2, 4, 6, 8]
```

| 호출 | 만드는 정수 | 비고 |
| --- | --- | --- |
| `range(5)` | 0, 1, 2, 3, 4 | 시작은 0, 끝 5는 **미포함** |
| `range(3, 6)` | 3, 4, 5 | 시작 포함, 끝 미포함 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 | 세 번째 인자만큼 건너뛴다 |
| `range(10, 0, -1)` | 10, 9, …, 1 | 단계가 음수면 거꾸로 |

`range`는 **정수를 순서대로 꺼낼 수 있는 자료**를 만드는 내장 함수다. 인자 규칙은 슬라이싱 `[시작:끝:단계]`와 완전히 같다 — 끝은 포함하지 않고, 시작을 빼면 0, 단계를 빼면 1이다. 그래서 `range(1, 11)`이 1부터 10까지이고, "끝 − 시작 = 개수"라는 슬라이싱의 셈법이 그대로 통한다.

첫 줄의 결과가 눈에 띈다. `print(range(5))`는 `[0, 1, 2, 3, 4]`가 아니라 `range(0, 5)`라고만 찍힌다. `range`가 돌려주는 것은 리스트가 아니라 **"0부터 5 직전까지"라는 규칙을 가진 범위 객체**이고, 실제 숫자는 꺼낼 때 하나씩 만들어진다. 그래서 안을 눈으로 확인하려면 `list(range(5))`처럼 리스트로 바꿔 줘야 한다. 리스트 노트에서 `type()`으로 자료형을 확인하던 습관대로 `type(range(5))`를 찍어 보면 `<class 'range'>`라고 나온다 — 리스트·문자열·딕셔너리처럼 하나의 자료형이다.

### 1-2. `for`와 `range`를 함께 — 숫자를 만들어 돌기

```python
# 1] 1부터 10까지 출력
for i in range(1, 11):
    print(i)

# 2] 10부터 1까지 출력
for i in range(10, 0, -1):
    print(i)

# 3] 1부터 10까지 홀수만 출력
for i in range(1, 11, 2):
    print(i)
```

| 목표 | `range` 인자 | 생각하는 순서 |
| --- | --- | --- |
| 1~10 | `range(1, 11)` | 끝은 미포함이니 원하는 마지막 값 + 1 |
| 10~1 | `range(10, 0, -1)` | 시작 10, 끝 0 미포함(=1까지), 단계 −1 |
| 1~10 홀수 | `range(1, 11, 2)` | 1에서 출발해 2씩 건너뛰면 홀수만 |

`for 반복변수 in range(...)` 모양이다. 리스트 노트의 `for i in list_e`가 **요소**를 하나씩 꺼냈다면, 여기서는 `range`가 만드는 **정수**를 하나씩 꺼낸다. 문법은 똑같고 꺼내는 자료만 다르다. 파이썬에는 자바식 `for (int i = 1; i <= 10; i++)`가 없어서, "몇 번 돌 것인가"나 "몇부터 몇까지 세는가"는 전부 `range`가 맡는다. 자바 `for`문의 세 칸(초기값·조건·증감)이 `range`의 세 인자(시작·끝·단계)에 하나씩 대응한다고 보면 옮겨 적기 쉽다.

거꾸로 셀 때는 단계를 음수로 준다. 이때 끝값은 여전히 미포함이라 `range(10, 0, -1)`이 1에서 멈춘다 — 10부터 0까지 찍고 싶다면 끝을 `-1`로 적어야 한다. 홀수만 찍는 세 번째는 조건문으로 `i % 2 == 1`을 거르는 대신 **애초에 홀수만 만들어 내는** 쪽이다. 연습문제 노트에서 `j = i * 2 + 1`로 홀수 인덱스를 계산하던 것을 세 번째 인자 하나로 대신한 셈이라, 같은 결과를 더 짧게 얻는 길이 생겼다.

### 1-3. `while` — 조건이 참인 동안 반복

```python
# while 조건식 :      조건이 True면 실행코드 반복, False가 되면 종료
#     실행코드

i = 1
while i < 10:
    print(i)
    i += 1
```

| 자리 | 하는 일 |
| --- | --- |
| `i = 1` | 반복 전에 **세는 변수를 직접 준비**한다 |
| `while i < 10:` | 매 바퀴 **시작할 때** 조건을 검사하고, 참이면 몸체로 들어간다 |
| `print(i)` | 몸체 — 콜론 뒤 들여쓰기 블록 |
| `i += 1` | 변수를 **직접 바꿔서** 언젠가 조건이 거짓이 되게 만든다 |

`for`가 "이 자료를 끝까지 돌아라"라면 `while`은 "이 조건이 참인 동안 돌아라"다. 형태는 조건문의 `if 조건식:`과 같아 보이지만, `if`는 한 번 검사하고 끝나고 `while`은 몸체를 다 돈 뒤 **다시 조건으로 올라와서** 검사한다. 거짓이 되는 순간 빠져나온다. 자바의 `while (i < 10) { ... }`과 동작이 같고, 다만 중괄호가 콜론·들여쓰기로 바뀌었을 뿐이다.

`for`+`range`와 달리 `while`은 세는 변수를 만들고(`i = 1`), 키우는 일(`i += 1`)을 전부 손으로 한다. 그래서 조건식과 증감 줄을 어떻게 쓰느냐에 따라 마지막 값이 달라진다 — `i < 10`이면 9에서 끝나고 `i <= 10`이면 10까지 찍힌다. `range(1, 11)`에서 "끝 미포함"을 챙기던 것과 같은 종류의 경계 확인이 `while`에서는 조건식에 들어간다. 증감 줄을 빼먹으면 조건이 영원히 참이라 **무한 루프**에 빠지니, `while`을 쓸 때는 "무엇이 이 조건을 거짓으로 만드는가"를 먼저 정해 두는 편이 안전하다. 몇 번 돌지 미리 아는 반복은 `for`+`range`, 돌아 봐야 아는 반복(입력이 올 때까지, 값이 조건을 만족할 때까지)은 `while`이 어울린다.

## 2. 추가로 알면 좋은 활용법

### 2-1. `range`를 리스트와 엮기 — 길이만큼 돌기와 뒤집기

```python
fruits = ["사과", "배", "감"]

for i in range(len(fruits)):          # 0, 1, 2 — 인덱스로 돌기
    print(i, fruits[i])

for i in range(len(fruits) - 1, -1, -1):   # 2, 1, 0 — 거꾸로
    print(fruits[i])

for i in reversed(range(5)):          # 4, 3, 2, 1, 0 — 단계 -1 대신
    print(i)

print(3 in range(1, 11, 2))           # True — 범위에 들어 있는지
print(len(range(0, 10, 2)))           # 5  — 몇 개 만드는지
```

`range(len(리스트))`는 리스트 노트에서 본 "인덱스로 도는" 관용구고, 요소와 번호가 같이 필요하면 `enumerate`가 더 읽기 좋다는 것도 그때 적어 두었다. 거꾸로 돌 때 `range(끝-1, -1, -1)`처럼 인자 세 개를 맞추는 게 번거로우면 `reversed(range(5))`로 감싸는 편이 실수가 적다. `range`는 하나의 자료형이라 `in`으로 포함 여부를 묻거나 `len`으로 개수를 셀 수도 있다 — 리스트로 바꾸지 않아도 된다.

### 2-2. `range`를 다른 함수에 바로 넘기기

```python
print(sum(range(1, 11)))              # 55 — 1부터 10까지 합
print(list(range(10, 0, -2)))         # [10, 8, 6, 4, 2]
squares = [n * n for n in range(1, 6)]   # [1, 4, 9, 16, 25]
print(max(range(3, 8)))               # 7
```

"1부터 10까지 더하라"를 `total = 0; for i in range(1, 11): total += i`로 쓰는 것이 기본형이지만, 리스트를 돌지 않고 한 줄로 끝내는 `sum`·`max`·`min`에 `range`를 바로 넘겨도 된다. 리스트 컴프리헨션 안에 `range`를 두면 "1~5의 제곱 리스트"처럼 **숫자로 만든 리스트**가 한 줄로 나온다. 리스트 노트 끝에서 본 컴프리헨션의 재료가 리스트만이 아니라 `range`도 된다는 뜻이다.

### 2-3. `while`을 끝내고 건너뛰는 법 — `break`·`continue`·`while True`

```python
i = 0
while True:                 # 조건을 일부러 항상 참으로
    i += 1
    if i % 2 == 0:
        continue            # 짝수면 아래를 건너뛰고 다음 바퀴
    if i > 9:
        break               # 10을 넘으면 반복 자체를 끝낸다
    print(i)                # 1, 3, 5, 7, 9

while True:
    text = input("종료하려면 q: ")
    if text == "q":
        break
```

| 키워드 | 하는 일 |
| --- | --- |
| `break` | 반복을 **즉시 끝내고** 블록 밖으로 나간다 |
| `continue` | 이번 바퀴의 나머지를 **건너뛰고** 조건 검사로 돌아간다 |
| `while True:` | 조건을 항상 참으로 두고, 끝내는 시점을 몸체 안의 `break`가 정한다 |

`while` 조건식 하나로 끝내기 애매한 반복 — 사용자가 `q`를 칠 때까지, 서버 응답이 올 때까지 — 는 `while True`로 열어 두고 안에서 `break`로 끊는 모양이 관용구다. `break`·`continue`는 `for`에서도 똑같이 쓰인다. 자바와 이름도 동작도 같아서 새로 외울 것은 없고, 들여쓰기로 "어느 반복문의 것인지"가 정해진다는 점만 조심하면 된다.

### 2-4. 정수 세기 외의 `while` 쓰임 — 수렴·누적

```python
# 2의 거듭제곱이 1000을 넘는 첫 지점
n = 1
while n <= 1000:
    n *= 2
print(n)                    # 1024

# 리스트가 빌 때까지 꺼내기
stack = [1, 2, 3]
while stack:                # 빈 리스트는 거짓
    print(stack.pop())
```

`while`의 조건에는 비교식만 오는 것이 아니다. 조건문 노트에서 본 "빈 값은 거짓" 규칙 덕분에 `while stack:`처럼 리스트 자체를 조건에 두면 **비는 순간 멈춘다**. 몇 번 돌지 모르는 반복의 전형이 이런 것들이다 — 값이 어떤 기준을 넘을 때까지, 자료가 바닥날 때까지. 이런 자리에서 `for`+`range`를 억지로 쓰면 횟수를 넉넉히 잡고 `break`를 섞어야 하니, 애초에 `while`이 맞는 도구다.

## 3. 더 나아가 알면 좋은 것

### 3-1. `range`가 리스트를 미리 만들지 않는 이유 — 지연 평가

`range(1_000_000)`을 만들어도 메모리에 정수 백만 개가 올라오지 않는다. 시작·끝·단계 세 숫자만 들고 있다가 `for`가 "다음 값"을 요구할 때마다 하나씩 계산해 준다. 그래서 `print(range(5))`가 `range(0, 5)`로만 찍혔던 것이고, 아주 큰 범위를 돌아도 가볍다. 이렇게 **필요할 때 하나씩 내놓는** 자료를 파이썬에서는 반복 가능 객체(iterable)·반복자(iterator)라 부르고, `for`는 그 약속만 지키면 리스트든 `range`든 파일이든 똑같이 돈다. 정보처리기사 쪽에 이관된 코드 해석 문제에서 본 제너레이터 표현식도 같은 원리라, 나중에 `yield`를 만나면 `range`를 떠올리면 된다. 자바로 치면 `IntStream.range(0, 10)`이 가장 가깝다.

### 3-2. `for`·`while`의 `else`와 `itertools`

파이썬의 반복문에는 `else` 블록을 붙일 수 있다 — `break`로 끊기지 않고 **끝까지 돌았을 때만** 실행된다. "리스트에서 찾는 값이 없었다"를 플래그 변수 없이 표현하는 관용구인데, 다른 언어에는 없는 문법이라 읽을 때 당황하지 않도록 이름만 알아 두면 된다. `range`로 부족한 숫자열은 표준 라이브러리 `itertools`가 맡는다. `count(1)`은 끝이 없는 1, 2, 3, …이고 `cycle([…])`은 리스트를 무한 반복하며, 둘 다 `break`와 함께 쓴다. `zip(range(…), 리스트)`로 번호와 요소를 묶는 것은 `enumerate`와 같은 효과다.

### 3-3. 반복문 고르기 — 자바와 대응표

| 하고 싶은 것 | 자바 | 파이썬 |
| --- | --- | --- |
| 요소 하나씩 | `for (int x : list)` | `for x in list:` |
| 0부터 n−1까지 세기 | `for (int i = 0; i < n; i++)` | `for i in range(n):` |
| 조건이 참인 동안 | `while (cond) { }` | `while cond:` |
| 최소 한 번은 실행 | `do { } while (cond);` | 없음 — `while True:` + `break` |
| 반복 끝내기·건너뛰기 | `break` / `continue` | 같음 |

파이썬에는 `do-while`이 없다. 한 번은 반드시 실행하고 조건을 뒤에서 보고 싶으면 `while True`로 들어가 끝에서 `if not cond: break`를 둔다. 반대로 자바에는 반복문의 `else`가 없다. 반복문 자체는 두 언어가 거의 같으니, 옮겨 쓸 때 갈리는 자리는 결국 **세는 반복을 `range`에 맡긴다**는 것 하나다.

### 3-4. 다음에 볼 키워드

- `for … else`·`while … else`, `itertools.count`·`cycle`·`product`
- 반복자 프로토콜(`iter`·`next`)과 제너레이터(`yield`) — `range`가 가벼운 이유
