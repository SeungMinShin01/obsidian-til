# Python 코드 해석 문제 (이관)

> 노션 `정보처리기사` 폴더의 `day01`, `1` 페이지에 섞여 있던 Python 부분만 이 폴더로 발췌·이관했습니다. 원본 페이지는 그대로 두었습니다.

## 문제 1 — 문자열 뒤집기 + 문자 필터링

```python
i = input("입력 = ")
x = []
for w in i.split():
    x.append(w[::-1])
y = ' '.join(x)
z = ''.join(c for c in y if c not in "ong")
print(z)
```

입력이 `HumanDev`일 때의 추적입니다.

1. `i.split()` — 인자 없이 호출하면 공백 기준으로 자릅니다. `HumanDev`는 공백이 없으므로 결과는 요소 1개짜리 리스트 `["HumanDev"]`
2. `w[::-1]` — 슬라이싱 `[시작:끝:간격]`에서 간격이 `-1`이면 끝에서부터 거꾸로 읽습니다 → `"veDnamuH"`
3. `' '.join(x)` — 요소가 1개면 이어붙일 사이가 없어 구분자가 끼지 않습니다 → `y = "veDnamuH"`
4. `''.join(c for c in y if c not in "ong")` — `o`, `n`, `g`를 제외. **`in` 비교는 대소문자를 구분**하므로 대문자 `D`, `H`는 남습니다 → `"veDamuH"`

**답: `veDamuH`**

### 슬라이싱 간격이 -1이라는 것

`s[start:stop:step]`에서 `step`이 음수면 **오른쪽에서 왼쪽으로** 이동합니다. `start`와 `stop`을 생략하면 기본값이 뒤바뀌어 각각 마지막·처음이 됩니다.

```python
s = "abcde"
s[::-1]    # "edcba"
s[::2]     # "ace"   (2칸씩 건너뜀)
s[1:4]     # "bcd"
```

## 문제 2 — 리스트 컴프리헨션 + 얕은 복사

```python
def f(a):
    m = [[x] for x in a]
    b = m[:]
    for i in range(len(b) - 1):
        b[i+1] += b[i]
    return sum(len(x) for x in m)

print(f([1, 2, 3, 4]))
```

1. `m = [[x] for x in a]` — 각 요소를 1칸짜리 리스트로 감쌉니다 → `m = [[1], [2], [3], [4]]`
2. `b = m[:]` — **얕은 복사**. 바깥 리스트는 새로 만들어지지만, **안쪽 리스트들은 같은 객체를 공유**합니다.
   ```
   m[0] ──→ [1] ←── b[0]
   m[1] ──→ [2] ←── b[1]
   m[2] ──→ [3] ←── b[2]
   m[3] ──→ [4] ←── b[3]
   ```
3. `for i in range(len(b) - 1)` — `len(b)`는 4이므로 `range(3)` → `i`는 0, 1, 2
4. `b[i+1] += b[i]` — 리스트의 `+=`는 `extend`와 같아서 **원본 객체를 직접 수정**합니다.
   - `i=0`: `b[1] = [2, 1]`  (= `m[1]`도 같이 바뀜)
   - `i=1`: `b[2] = [3, 2, 1]`
   - `i=2`: `b[3] = [4, 3, 2, 1]`
5. `sum(len(x) for x in m)` — `m`도 같은 객체를 보고 있으므로 길이는 1 + 2 + 3 + 4

**답: `10`**

### 핵심 — `+=`가 원본을 바꾼다

```python
b = [1]
c = b
b += [2]     # extend와 동일. 같은 객체를 수정 → c도 [1, 2]
b = b + [3]  # 새 객체 생성 → c는 그대로
```

리스트에서 `+=`는 `b = b + [...]`와 **다릅니다.** 이 문제의 함정이 정확히 여기입니다.

### 복사 3단계

```python
b = m          # 참조 복사 — 완전히 같은 객체
b = m[:]       # 얕은 복사 — 바깥만 새 객체
import copy
b = copy.deepcopy(m)   # 깊은 복사 — 안쪽까지 전부 새 객체
```

JS의 `[...arr]`(얕은) vs `structuredClone(obj)`(깊은)과 정확히 같은 개념입니다. Java에서 `Book[] archive = library;`가 같은 배열을 가리키던 것과도 같습니다.

## 함께 알아두면 좋은 것

### 리스트 컴프리헨션 문법

```python
[표현식 for 변수 in 반복가능 if 조건]

[x * 2 for x in range(5)]              # [0, 2, 4, 6, 8]
[x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]
{k: v for k, v in pairs}               # 딕셔너리 컴프리헨션
{x for x in nums}                      # 집합 컴프리헨션
(x for x in nums)                      # 제너레이터 (괄호!)
```

`sum(len(x) for x in m)`에서 대괄호 없이 쓴 건 **제너레이터 표현식**입니다. 리스트를 실제로 만들지 않아 메모리를 아낍니다.

### 2차원 리스트 초기화 함정

```python
grid = [[0] * 3] * 3     # 위험! 같은 리스트 3개가 참조됨
grid[0][0] = 1           # → [[1,0,0], [1,0,0], [1,0,0]]

grid = [[0] * 3 for _ in range(3)]   # 정답
```

이 문제와 완전히 같은 원리입니다. 코딩테스트에서 자주 나옵니다.
