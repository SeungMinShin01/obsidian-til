# Python day01 — 파이썬 시작과 키워드 확인

> 실습 파일: `day01/c1-2.py`
> 허브: [[Python 정리본 인덱스]] · 이전: (없음 — 파이썬 수업 첫날) · 다음: (아직 없음)

KDT_2026에 `2026_Python` 폴더가 새로 생겼다. 자바·스프링·리액트에 이어 파이썬 수업이 시작된 첫날이고, 파일 하나(`c1-2.py`)로 실행 방법과 첫 출력, 그리고 파이썬이 예약해 둔 단어(키워드) 목록을 확인했다. 분량은 짧지만 앞으로 파이썬 노트가 쌓일 출발점이라 따로 적어 둔다.

## 1. 배운 내용

### 1-1. 첫 출력과 실행 방법

```python
print("hello coding python")
# shift + enter 한줄씩/문장 실행
# 파일내 오른쪽 클릭 -> run python -> 전체실행
```

| 항목 | 설명 |
| --- | --- |
| `print(...)` | 괄호 안의 값을 화면에 출력한다. 자바의 `System.out.println`과 달리 클래스·메소드 선언 없이 파일 첫 줄부터 바로 실행된다 |
| `#` | 한 줄 주석. 자바의 `//`에 해당한다 |
| `Shift + Enter` | VS Code에서 커서가 있는 한 줄(또는 선택한 문장)만 인터랙티브 창으로 보내 실행한다. 결과를 바로 보면서 한 줄씩 확인할 때 쓴다 |
| 우클릭 → Run Python | 파일 전체를 위에서 아래로 실행한다 |

세미콜론도 중괄호도 없고, 들여쓰기가 곧 블록 구분이라는 점이 자바와 가장 먼저 달라 보이는 부분이다.

### 1-2. 키워드 목록 확인

```python
import keyword
print( keyword.kwlist)
```

| 항목 | 설명 |
| --- | --- |
| `import keyword` | 표준 라이브러리의 `keyword` 모듈을 불러온다. 자바의 `import`처럼 다른 코드를 가져오는 문장이지만 패키지 경로 대신 모듈 이름을 쓴다 |
| `keyword.kwlist` | 파이썬이 문법용으로 예약해 둔 단어들의 리스트. `False`·`None`·`True`·`and`·`as`·`class`·`def`·`if`·`import`·`in`·`is`·`not`·`or`·`return`·`while` 등 30개 남짓이 나온다 |

이 목록에 있는 단어는 변수명·함수명으로 쓸 수 없다. 자바에서 `class`나 `int`를 변수명으로 못 쓰는 것과 같은 이유다. 외울 필요는 없고, 이름을 지을 때 "이게 예약어인가?" 싶으면 `keyword.iskeyword("단어")`로 바로 확인하면 된다.

## 2. 추가로 알면 좋은 활용법

### 2-1. `print`의 자주 쓰는 모양

```python
name = "python"
print("hello", name)          # 쉼표로 이어 붙이면 공백으로 구분해 출력
print(f"hello {name}")        # f-문자열 — 중괄호 안에 변수·식을 바로 넣는다
print("a", "b", sep="-")      # 구분자 바꾸기 → a-b
print("끝", end="")           # 줄바꿈 없이 출력
```

자바에서 `+`로 문자열을 이어 붙이던 자리를 파이썬에서는 f-문자열이 대신한다. 앞으로 거의 모든 출력에 쓰게 된다.

### 2-2. 실행 결과를 보는 두 가지 창

- 인터랙티브 창(`Shift + Enter`) — 변수 값이 유지되어 이어서 실험하기 좋다. 한 줄 고치고 다시 보내면 된다
- 터미널 실행(`python 파일명.py` 또는 Run Python) — 파일을 처음부터 끝까지 깨끗한 상태로 돌린다. 제출·검증은 이쪽으로 확인하는 편이 안전하다

### 2-3. 모듈이 가진 것 둘러보기

```python
import keyword
print(dir(keyword))      # 모듈 안의 이름 목록
help(keyword.iskeyword)  # 함수 설명
```

`dir()`과 `help()`는 어떤 모듈이든 그 자리에서 열어 볼 수 있어서, 문서를 찾기 전에 먼저 써 보면 된다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 내장 함수와 키워드는 다르다

`print`·`len`·`input`은 키워드가 아니라 **내장 함수**라 `keyword.kwlist`에 없다. 기술적으로는 덮어쓸 수 있지만(`print = 1`처럼) 그 순간 출력이 막히므로, 내장 함수 이름도 변수명으로 쓰지 않는 습관을 들인다. `dir(__builtins__)`로 목록을 볼 수 있다.

### 3-2. 소프트 키워드

`match`·`case`·`type`처럼 특정 문맥에서만 예약어로 동작하는 단어가 있다. `keyword.softkwlist`에서 확인할 수 있고, 일반 변수명으로는 쓸 수 있지만 피하는 편이 읽기 좋다.

### 3-3. 파이썬 실행 구조

자바는 `.java` → 컴파일 → `.class` → JVM 순서였다면, 파이썬은 인터프리터가 소스를 바로 읽어 한 줄씩 실행한다. 그래서 `Shift + Enter` 같은 한 줄 실행이 자연스럽다. 가상환경(`venv`)과 패키지 설치(`pip`)는 외부 라이브러리를 쓰기 시작할 때 같이 보면 된다.
