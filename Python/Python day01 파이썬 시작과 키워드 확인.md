## 1. 배운 내용

### 1-1. 첫 출력과 실행 방법

```python
print("hello coding python")
# shift + enter 한줄씩/문장 실행
# 파일내 오른쪽 클릭 -> run python -> 전체실행
```

| 항목 | 설명 |
| --- | --- |
| `print(...)` | 괄호 안의 값을 화면에 출력한다. 자바의 `System.out.println`과 달리 클래스·메소드 선언 없이 파일 첫 줄부터 바로 실행된다 |
| `#` | 한 줄 주석. 자바의 `//`에 해당한다 |
| `Shift + Enter` | VS Code에서 커서가 있는 한 줄(또는 선택한 문장)만 인터랙티브 창으로 보내 실행한다. 결과를 바로 보면서 한 줄씩 확인할 때 쓴다 |
| 우클릭 → Run Python | 파일 전체를 위에서 아래로 실행한다 |

세미콜론도 중괄호도 없고, 들여쓰기가 곧 블록 구분이라는 점이 자바와 가장 먼저 달라 보이는 부분이다.

### 1-2. 키워드 목록 확인

```python
import keyword
print( keyword.kwlist)
```

| 항목 | 설명 |
| --- | --- |
| `import keyword` | 표준 라이브러리의 `keyword` 모듈을 불러온다. 자바의 `import`처럼 다른 코드를 가져오는 문장이지만 패키지 경로 대신 모듈 이름을 쓴다 |
| `keyword.kwlist` | 파이썬이 문법용으로 예약해 둔 단어들의 리스트. `False`·`None`·`True`·`and`·`as`·`class`·`def`·`if`·`import`·`in`·`is`·`not`·`or`·`return`·`while` 등 30개 남짓이 나온다 |

이 목록에 있는 단어는 변수명·함수명으로 쓸 수 없다. 자바에서 `class`나 `int`를 변수명으로 못 쓰는 것과 같은 이유다. 외울 필요는 없고, 이름을 지을 때 "이게 예약어인가?" 싶으면 `keyword.iskeyword("단어")`로 바로 확인하면 된다.

### 1-3. `print`의 여러 모양

```python
print("하나만 출력합니다")              # 하나만 출력
print("여러개", "출력합니다")           # 쉼표로 여러 개 — 사이에 공백이 자동으로 들어간다
print( )                               # 빈 줄 하나 — 제어문자 \n 과 같다
```

| 항목 | 설명 |
| --- | --- |
| `print(a, b)` | 쉼표로 나열한 값을 **공백 하나로 띄워** 한 줄에 출력한다. 자바처럼 `+`로 이어 붙일 필요가 없고, 숫자와 문자열을 섞어도 변환 없이 그대로 찍힌다 |
| `print()` | 인수가 없으면 줄바꿈만 한다. 출력 사이에 빈 줄을 넣을 때 쓴다 |

쉼표를 쓰면 공백이 자동으로 붙는다는 점만 기억해 두면 된다. 공백 없이 붙이고 싶을 때는 뒤에서 볼 `sep=""`를 쓴다.

### 1-4. `type()`으로 자료형 확인

```python
print( type("안녕하세요")) # <class 'str'>
print ( type(123) )        # <class 'int'>
print( type(1.23) )        # <class 'float'>
print( type(True) )        # <class 'bool'>
print( type(None))         # <class 'NoneType'>
print( type( [ ] ))        # <class 'list'>
print(type( { } ))         # <class 'dict'>
print(type( ( ) ))         # <class 'tuple'>
```

| 값 | 자료형 | 자바로 치면 |
| --- | --- | --- |
| `"안녕하세요"` | `str` | `String` |
| `123` | `int` | `int`·`long` (크기 제한 없음) |
| `1.23` | `float` | `double` |
| `True` | `bool` | `boolean` — 첫 글자가 **대문자**다 |
| `None` | `NoneType` | `null` |
| `[ ]` | `list` | `ArrayList` |
| `{ }` | `dict` | `HashMap` |
| `( )` | `tuple` | 수정 불가능한 배열에 가깝다 |

파이썬은 변수를 선언할 때 타입을 적지 않으므로, 지금 들고 있는 값이 무엇인지는 `type()`으로 확인한다. 괄호 모양만으로 `list`·`dict`·`tuple`이 갈리는 것이 자바와 가장 다른 부분이고, `True`·`False`·`None`이 대문자로 시작하는 점은 앞 절의 키워드 목록에서 본 그대로다.

### 1-5. 문자열 만들기와 제어문자

```python
print( "ABC" )          # 큰따옴표
print( 'ABC' )          # 작은따옴표 — 둘은 완전히 같다
print( """ A
B
C """ )                # 세 겹 따옴표 — 줄바꿈을 그대로 품는 여러 줄 문자열
print( "A'B'C" )        # 큰따옴표 안에서는 작은따옴표를 그냥 쓴다
print( 'A"B"C' )        # 작은따옴표 안에서는 큰따옴표를 그냥 쓴다
print( "\"A\'B\nC\tD\\E")  # 제어문자
```

| 표기 | 뜻 |
| --- | --- |
| `"..."` / `'...'` | 같은 문자열. 안에 넣을 따옴표와 **반대 종류**를 바깥에 쓰면 이스케이프가 필요 없다 |
| `"""..."""` | 여러 줄 문자열. 줄바꿈과 들여쓰기가 그대로 들어간다. 자바의 텍스트 블록과 같은 역할 |
| `\"` `\'` | 따옴표 자체를 출력 |
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 역슬래시 한 개 |

자바는 문자열이 큰따옴표뿐이고 문자(`char`)가 작은따옴표였다면, 파이썬에는 문자 타입이 따로 없고 둘 다 문자열이다. 그래서 따옴표 종류는 "안에 어떤 따옴표가 들어가느냐"로 고르면 된다.

### 1-6. 문자열 연산 — 연결·반복·인덱싱·슬라이싱·`len`

```python
print("안녕" + "하세요")      # 1. + 연결 — 안녕하세요
# print("안녕" + 1)          # 문자열과 숫자는 바로 연결할 수 없다
print("안녕" * 3)             # 2. * 반복 — 안녕안녕안녕

# 3. 인덱싱 — 문자열은 글자가 순서대로 들어 있는 배열처럼 다룬다
print("안녕하세요"[0])        # 안   (양수: 0 ~ 4)
print("안녕하세요"[3])        # 세
print("안녕하세요"[-1])       # 요   (음수: -1 ~ -5, 뒤에서부터)
print("안녕하세요"[-3])       # 하

# 4. 슬라이싱 — [시작 : 끝]  끝 인덱스는 포함하지 않는다
print("안녕하세요"[0:2])      # 안녕   (0~1)
print("안녕하세요"[1:3])      # 녕하   (1~2)
print("안녕하세요"[1:])       # 녕하세요 — 끝 생략 = 마지막까지
print("안녕하세요"[:3])       # 안녕하   — 시작 생략 = 0부터

print(len("안녕하세요"))      # 5. 길이 — 5
```

| 연산 | 모양 | 설명 |
| --- | --- | --- |
| 연결 | `"a" + "b"` | 두 문자열을 이어 붙인다. 자바와 달리 **숫자는 자동으로 문자열이 되지 않아** `str(1)`로 바꿔 붙여야 한다 |
| 반복 | `"a" * 3` | 같은 문자열을 n번 이어 붙인다. 구분선(`"-" * 20`) 찍을 때 자주 쓴다 |
| 인덱싱 | `s[i]` | i번째 글자 하나. 0부터 시작하고, **음수 인덱스**는 뒤에서부터 센다(`-1`이 마지막 글자). 범위를 벗어나면 `IndexError` |
| 슬라이싱 | `s[a:b]` | a번째부터 **b번째 앞까지** 잘라 새 문자열을 만든다. 시작·끝은 생략할 수 있고, 범위를 넘겨도 오류 없이 있는 만큼만 돌아온다 |
| 길이 | `len(s)` | 글자 수. 자바의 `s.length()`가 메소드였다면 파이썬은 내장 함수 `len()`에 값을 넘긴다 |

핵심은 두 가지다. 첫째, 파이썬 문자열은 자바의 `charAt`·`substring` 같은 메소드 대신 **대괄호 하나**로 글자와 구간을 꺼낸다. 둘째, 슬라이싱의 끝 인덱스는 포함되지 않으므로 `[0:2]`는 두 글자다 — "끝 − 시작 = 글자 수"로 기억하면 헷갈리지 않는다. 음수 인덱스가 되는 점은 자바 배열에는 없던 것이라, 뒤에서 몇 글자를 떼어 올 때(`s[-2:]`) 특히 편하다.

### 1-7. 숫자 연산자

```python
print( 5+7 ,  5-7 , 5*7 , 5/7 )   # 사칙연산 — 12 -2 35 0.7142857142857143
print( 3//2 , 3%2 , 3**2 )        # 몫 // , 나머지 % , 제곱 ** — 1 1 9
print( 5 + 3 * 2 )                # 11 — 곱셈이 먼저
print( (5+3) * 2 )                # 16 — 괄호가 먼저
print( 2 + 2 - 2 * 2 / 2 * 2 )    # 0
# 1. 2*2 → 4   2. 4/2 → 2   3. 2*2 → 4   4. 2+2 → 4   5. 4-4 → 0
```

| 연산자 | 뜻 | 자바와 다른 점 |
| --- | --- | --- |
| `+` `-` `*` | 더하기·빼기·곱하기 | 같다 |
| `/` | 나누기 | **정수끼리 나눠도 결과는 `float`**다. `5/7`은 `0.714…`, `4/2`도 `2.0` |
| `//` | 몫 | 자바의 정수 나눗셈 `5/7 == 0`이 하던 일을 이 연산자가 맡는다. 소수점 아래를 **내림**한다(`-7//2`는 `-4`) |
| `%` | 나머지 | 같다. 짝홀 판별·순환 인덱스에 쓴다 |
| `**` | 거듭제곱 | 자바는 `Math.pow()`였는데 파이썬은 연산자다. `2**10`은 `1024` |

우선순위는 수학과 같다 — `**` → `*` `/` `//` `%` → `+` `-` 순서이고, 같은 급은 왼쪽부터 계산한다. 마지막 줄처럼 `*`·`/`가 섞인 식은 왼쪽부터 차례로 하나씩 줄여 가면 된다. 자바에서 넘어올 때 가장 자주 걸리는 부분은 `/`다. 자바 감각으로 `int / int`가 정수가 나올 거라 기대하면 안 되고, 정수 몫이 필요하면 `//`를 써야 한다.

### 1-8. 변수와 복합대입연산자

```python
pi = 3.14159265     # 변수명 = 값
r = 10
# r2                # 값을 넣은 적 없는 이름을 쓰면 NameError
print(pi, r)
print( 2 * pi * r ) # 62.831853

number = 100
number += 10    # 110
number -= 10    # 100
number *= 2     # 200
number /= 2     # 100.0   ← /= 를 지나면 float 가 된다
number %= 3     # 1.0
number ** 3     # 값만 계산하고 버린다 — number 는 그대로 1.0
print(number)

number = "안녕하세요"   # 같은 이름에 문자열을 다시 넣어도 된다
number += "!"           # 안녕하세요!
number += "!"           # 안녕하세요!!
number *= 3             # 안녕하세요!안녕하세요!안녕하세요!
print(number)
```

| 항목 | 설명 |
| --- | --- |
| `이름 = 값` | 타입 선언 없이 이름에 값을 붙인다. `int r = 10;`이 아니라 그냥 `r = 10` |
| `NameError` | 값을 넣기 전에 이름을 쓰면 나는 오류. 자바에서 선언 없이 변수를 쓸 때의 컴파일 오류에 해당하지만, 파이썬은 **그 줄이 실행되는 순간** 터진다 |
| `+=` `-=` `*=` `/=` `%=` `**=` `//=` | `number = number + 10`을 줄여 쓴 것. 자바와 같은 모양이고 `**=`·`//=`가 더 있다 |
| `number ** 3` | 대입이 없는 식은 계산만 하고 결과가 사라진다. 변수에 반영하려면 `**=`로 써야 한다 |
| 문자열에 `+=` `*=` | 문자열 연결·반복도 복합대입이 된다 |

자바와 가장 다른 지점은 두 가지다. 첫째, 변수에 타입이 없으므로 `number`에 숫자를 넣었다가 그 자리에 문자열을 넣어도 오류가 아니다 — 타입은 변수가 아니라 **값**에 붙어 있다. 둘째, `/=`를 한 번 지나면 `100`이 `100.0`으로 바뀌고 그 뒤 `%=`의 결과도 `1.0`이 된다. 1-7의 "`/`는 항상 `float`"가 복합대입에서도 그대로 이어진다.

### 1-9. `input()`과 형변환

```python
input("인사말을 입력하세요>")   # 괄호 안 문자열이 안내문으로 찍히고 입력을 기다린다
string = input("입력>")         # 입력받은 값을 변수에 저장
print( type(string) )           # 123 을 쳐도 <class 'str'>

# 타입 변환 — str → int / float → str
string_int = int( string )
string_float = float( string )
print( type(string_int), type(string_float) )   # <class 'int'> <class 'float'>
string_str = str(string_int)
print( type(string_str) )                       # <class 'str'>
# 주의: "a3" 처럼 숫자가 아닌 문자열은 변환되지 않고, "3.5" 를 int() 로 바꿀 수도 없다

# 누적 예제 — inch 를 cm 로
raw_input = input("inch 입력")   # 1. 입력받아 변수에 저장
inch = int( raw_input )          # 2. 연산 전에 str → int 변환
cm = inch * 2.54                 # 3. 연산
print( cm )                      # 4. 출력
```

| 항목 | 설명 |
| --- | --- |
| `input("안내문")` | 안내문을 찍고 한 줄을 읽어 **항상 문자열**로 돌려준다. 자바의 `Scanner.nextLine()`에 해당하고, `nextInt()` 같은 숫자 전용 입력은 없다 |
| `int(x)` | 문자열·실수를 정수로. 실수는 소수점 아래를 잘라 낸다(`int(3.9)`는 `3`) |
| `float(x)` | 문자열·정수를 실수로 |
| `str(x)` | 무엇이든 문자열로. 1-6에서 `"안녕" + 1`이 안 되던 것을 `"안녕" + str(1)`로 푼다 |
| `ValueError` | `int("a3")`·`int("3.5")`처럼 모양이 안 맞는 변환에서 나는 오류 |

숫자를 받아 계산하는 코드는 늘 "입력 → 변환 → 연산 → 출력" 네 단계로 흐른다. 변환을 빼먹으면 `"3" * 2.54`에서 `TypeError`가 나거나, `"3" * 3`처럼 반복 연산자로 읽혀 `"333"`이 나오는 식으로 엉뚱한 결과가 되므로, `input()` 바로 다음 줄에서 변환하는 습관이 안전하다. 변환 함수 이름이 `type()`이 보여 주던 자료형 이름(`int`·`float`·`str`)과 같다는 점도 기억해 두면 편하다.

### 1-10. `format()`으로 문자열에 값 끼워 넣기

```python
string_a = "age:{}".format(10)
print( string_a )                              # age:10
string_b = "{} {} {}".format( 1, "안녕", True )
print( string_b )                              # 1 안녕 True
```

| 항목 | 설명 |
| --- | --- |
| `"...{}...".format(값)` | 문자열 안의 `{}` 자리에 값을 순서대로 넣는다. 자리 수만큼 인수를 넘긴다 |
| 타입 변환 없음 | 숫자·불리언을 넘겨도 알아서 문자열로 찍힌다. `"age:" + 10`이 안 되던 자리를 `+`·`str()` 없이 해결한다 |

`format()`은 문자열의 메소드라 `"문자열".format(...)` 모양으로 부른다. 자바의 `String.format("%d", 10)`과 같은 역할인데 `%d`·`%s` 같은 타입 글자 대신 `{}` 하나로 통일된 점이 다르다. 2-1에서 먼저 적어 둔 f-문자열이 이 `format()`을 더 짧게 쓴 형태다.

## 2. 추가로 알면 좋은 활용법

### 2-1. `print`의 옵션과 f-문자열

```python
name = "python"
print(f"hello {name}")        # f-문자열 — 중괄호 안에 변수·식을 바로 넣는다
print("a", "b", sep="-")      # 쉼표 사이 구분자 바꾸기 → a-b (sep="" 이면 붙여 쓴다)
print("끝", end="")           # 줄바꿈 없이 출력
print(r"C:\new\table")       # r-문자열 — 역슬래시를 제어문자로 읽지 않는다 (경로 적을 때)
```

자바에서 `+`로 문자열을 이어 붙이던 자리를 파이썬에서는 f-문자열이 대신한다. 앞으로 거의 모든 출력에 쓰게 된다.

### 2-2. 실행 결과를 보는 두 가지 창

- 인터랙티브 창(`Shift + Enter`) — 변수 값이 유지되어 이어서 실험하기 좋다. 한 줄 고치고 다시 보내면 된다
- 터미널 실행(`python 파일명.py` 또는 Run Python) — 파일을 처음부터 끝까지 깨끗한 상태로 돌린다. 제출·검증은 이쪽으로 확인하는 편이 안전하다

### 2-3. 모듈이 가진 것 둘러보기

```python
import keyword
print(dir(keyword))      # 모듈 안의 이름 목록
help(keyword.iskeyword)  # 함수 설명
```

`dir()`과 `help()`는 어떤 모듈이든 그 자리에서 열어 볼 수 있어서, 문서를 찾기 전에 먼저 써 보면 된다.

### 2-4. 슬라이싱 세 번째 칸과 자주 쓰는 문자열 메소드

```python
s = "안녕하세요"
print(s[::2])        # 안하요 — [시작:끝:간격]
print(s[::-1])       # 요세하녕안 — 간격이 -1 이면 뒤집기
print(s[-2:])        # 세요 — 뒤에서 두 글자

print("hello".upper(), "  a b ".strip(), "a,b,c".split(","))
print("안녕하세요".find("하"), "안녕" in "안녕하세요")   # 2 True
```

슬라이싱의 세 번째 칸(간격)은 수업에선 아직 안 나왔지만 문자열 뒤집기(`[::-1]`)에 자주 쓰여 같이 적어 둔다. `upper`·`strip`·`split`·`find`·`in`은 입력값을 정리할 때 가장 먼저 손에 잡히는 것들이다.

### 2-5. 입력값 검사와 안전한 형변환

```python
raw = input("정수>")
if raw.isdigit():             # 0~9 로만 되어 있는지
    n = int(raw)
else:
    print("정수가 아닙니다")

try:                          # 음수·실수까지 받으려면 변환을 시도하고 실패를 잡는다
    n = float(input("숫자>"))
except ValueError:
    print("숫자가 아닙니다")

print(int("  42 "))           # 42 — 앞뒤 공백은 알아서 무시한다
print(int(float("3.5")))      # 3 — 소수점 문자열은 float 를 거쳐 int 로
```

`input()`은 사용자가 무엇을 칠지 알 수 없으므로 변환 전에 검사하거나 실패를 잡아 두는 편이 안전하다. `isdigit()`은 음수 부호와 소수점을 숫자로 보지 않으므로, 그런 입력까지 받을 때는 `try`·`except` 쪽이 맞다. `try`·`except`는 자바의 `try`·`catch`에 해당하고 자세한 문법은 뒤에 다시 본다.

### 2-6. `format()`·f-문자열의 서식 지정

```python
print("{:.2f}".format(3.14159))       # 3.14 — 소수 둘째 자리까지
print("{:,}".format(1234567))         # 1,234,567 — 천 단위 쉼표
print("{:>5}|{:<5}|".format(1, 2))    # "    1|2    |" — 오른쪽·왼쪽 정렬, 폭 5
print("{0} {1} {0}".format("a", "b")) # a b a — 번호로 자리 지정
print("{name}".format(name="파이썬"))  # 이름으로 자리 지정

cm = 2.54 * 10
print(f"{cm:.1f}cm")                  # 25.4cm — f-문자열에도 같은 서식이 붙는다
```

중괄호 안에 콜론을 두고 서식을 적으면 소수 자릿수·쉼표·정렬·폭을 한 번에 정한다. 자바 `String.format`의 `%.2f`·`%5d`에 대응하는 자리이고, f-문자열에서도 `{변수:서식}` 그대로 쓸 수 있어서 결국 가장 자주 손에 잡히는 건 f-문자열이다. `print(cm)`이 `25.400000000000002`처럼 찍힐 때 `:.1f` 하나로 정리된다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 내장 함수와 키워드는 다르다

`print`·`len`·`input`은 키워드가 아니라 **내장 함수**라 `keyword.kwlist`에 없다. 기술적으로는 덮어쓸 수 있지만(`print = 1`처럼) 그 순간 출력이 막히므로, 내장 함수 이름도 변수명으로 쓰지 않는 습관을 들인다. `dir(__builtins__)`로 목록을 볼 수 있다.

### 3-2. 소프트 키워드

`match`·`case`·`type`처럼 특정 문맥에서만 예약어로 동작하는 단어가 있다. `keyword.softkwlist`에서 확인할 수 있고, 일반 변수명으로는 쓸 수 있지만 피하는 편이 읽기 좋다.

### 3-3. 파이썬 실행 구조

자바는 `.java` → 컴파일 → `.class` → JVM 순서였다면, 파이썬은 인터프리터가 소스를 바로 읽어 한 줄씩 실행한다. 그래서 `Shift + Enter` 같은 한 줄 실행이 자연스럽다. 가상환경(`venv`)과 패키지 설치(`pip`)는 외부 라이브러리를 쓰기 시작할 때 같이 보면 된다.

### 3-4. 문자열은 바꿀 수 없다(불변)

`s[0] = "하"`처럼 한 글자를 바꾸려 하면 `TypeError`가 난다. 파이썬 문자열은 자바 `String`처럼 **불변**이라 `+`·`*`·슬라이싱은 모두 새 문자열을 만들어 돌려준다. 반복문 안에서 `+=`로 계속 이어 붙이면 매번 새 객체가 생기므로, 많이 붙일 때는 리스트에 모아 `"".join(리스트)`로 한 번에 만드는 편이 안전하다.

### 3-5. 변수는 이름표, 타입은 값에 붙는다

1-8에서 `number`에 `100`을 넣었다가 `"안녕하세요"`를 넣어도 되는 이유는, 파이썬 변수가 값을 담는 상자가 아니라 객체에 붙이는 **이름표**이기 때문이다. `number = 100`은 정수 객체 `100`에 `number`라는 이름을 붙이는 것이고, 다시 대입하면 이름표를 다른 객체로 옮길 뿐이다. 그래서 `type(number)`는 변수가 아니라 지금 가리키는 값의 타입을 알려 준다(동적 타이핑). 자바처럼 선언 시점에 타입이 고정되지 않으니 편한 대신, 같은 이름에 다른 종류의 값을 섞어 넣으면 뒤에서 읽기 어려워지므로 한 변수에는 한 종류만 넣는 습관이 안전하다. `a = b = 1`처럼 여러 이름에 한 번에 붙이거나 `a, b = 1, 2`로 동시에 대입하는 문법도 같은 원리다.

### 3-6. 정수는 크기 제한이 없고, 실수는 오차가 있다

`2 ** 100`을 찍어 보면 31자리 정수가 그대로 나온다. 파이썬 `int`는 자바의 `int`·`long`처럼 비트 수가 정해져 있지 않아 오버플로가 없다. 반면 `float`는 자바 `double`과 같은 64비트 부동소수점이라 `0.1 + 0.2 == 0.3`이 `False`가 되는 오차가 그대로 있다. 돈 계산처럼 오차가 허용되지 않는 자리에서는 `decimal.Decimal`을, 소수 자릿수를 맞춰 보여 주기만 할 때는 2-6의 `:.2f`나 `round(x, 2)`를 쓴다. `/`가 항상 `float`를 돌려주는 설계도 여기와 이어진다 — 정수 결과가 필요하면 `//`로 받고, 몫과 나머지를 함께 쓸 땐 `divmod(7, 2)`가 `(3, 1)`을 한 번에 돌려준다.
