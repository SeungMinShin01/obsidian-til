# Python day09 — 시본 범주 빈도·박스플롯·상관 히트맵

> 실습 파일: `day09/g-02.py`
> 허브: [[Python 정리본 인덱스]] · 이전: [[Python day09 맷플롯립 시작과 선 차트]] · 다음: (아직 없음)

맷플롯립으로 선·막대·산점도·히스토그램을 그린 다음 시간에는 그 위에 얹힌 라이브러리 **시본(Seaborn)**을 썼다. 맷플롯립이 "점과 선을 어디에 찍을지"를 전부 지정하는 도구였다면, 시본은 **데이터프레임과 열 이름만 넘기면** 통계 그림을 알아서 그려 주는 도구다. 이 시간에 한 일은 넷이다. 넘파이 난수로 고객 100명짜리 데이터프레임을 만들고, 범주별 개수를 세는 **카운트플롯**, 범주별 수치 분포를 상자로 요약하는 **박스플롯**, 수치 열끼리의 상관계수를 색으로 칠하는 **히트맵**, 그리고 두 수치 열의 관계를 점으로 찍는 **산점도**를 차례로 띄웠다. 네 그림 모두 `data=df, x="열", y="열", hue="열"`이라는 같은 모양의 호출이라서, 함수 이름만 바꾸면 그림이 바뀐다는 점이 지난 시간 맷플롯립의 "2번 자리 함수만 바뀐다"와 그대로 이어진다.

## 1. 배운 내용

### 1-1. 불러오기와 테마 — `import seaborn as sns`·`set_theme`

```python
import seaborn as sns

import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# 윈도우 기준 한글 폰트 설정 및 마이너스 부호 깨짐 방지
plt.rc('font', family='Malgun Gothic')
plt.rcParams['axes.unicode_minus'] = False

# 시본 기본 테마 적용 (폰트 설정 유지)
sns.set_theme(font='Malgun Gothic', rc={'axes.unicode_minus': False}, style='whitegrid')
```

| 문장 | 뜻 |
| --- | --- |
| `import seaborn as sns` | 시본의 관례 별칭은 `sns`다. `np`·`pd`·`plt`에 이어 네 번째 약속 |
| `plt.rc(…)`·`rcParams[…]` | 지난 시간과 같은 맷플롯립 한글 설정. 시본은 맷플롯립 위에서 돌아가므로 그대로 필요하다 |
| `sns.set_theme(font=…, rc={…}, style='whitegrid')` | 시본의 **기본 테마**를 켠다. 배경·격자·색 조합이 한 번에 바뀐다 |

핵심은 `set_theme`의 인자 세 개다. 시본의 테마를 켜면 맷플롯립의 `rcParams`를 시본이 **덮어쓴다** — 그래서 바로 위에서 맑은 고딕으로 바꿔 둔 폰트가 다시 기본 폰트로 돌아가 한글이 깨진다. 이를 막으려고 `font='Malgun Gothic'`으로 폰트를 테마 안에 다시 넣고, 음수 기호 설정도 `rc={'axes.unicode_minus': False}` 사전으로 같이 넘긴다. 주석의 "폰트 설정 유지"가 정확히 이 뜻이다. `style='whitegrid'`는 흰 배경에 옅은 격자 — 시본에는 `darkgrid`(기본)·`whitegrid`·`dark`·`white`·`ticks` 다섯 스타일이 있고, `plt.grid(True)`를 따로 부르지 않아도 격자가 깔린다.

순서도 기억해 둘 만하다. `plt.rc` → `sns.set_theme` 순서로 쓰되, **`set_theme`에 폰트를 다시 적지 않으면 앞의 설정이 무효**가 된다. 반대로 `set_theme`를 먼저 부르고 그 뒤에 `plt.rc('font', …)`를 두면 폰트가 살아남지만, 수업에서는 테마 안에 넣는 쪽을 택했다.

### 1-2. 실습 데이터 만들기 — 난수로 고객 데이터프레임

```python
np.random.seed(42)
n = 100
df = pd.DataFrame({
  '나이': np.random.randint(20, 60, size=n),
  '소득': np.random.randint(2500, 9000, size=n),
  '신용점수': np.random.randint(500, 850, size=n),
  '멤버십': np.random.choice(['일반', 'VIP'], size=n, p=[0.7, 0.3]),
  '이탈여부': np.random.choice([0, 1], size=n, p=[0.75, 0.25]) # 0: 유지, 1: 이탈
})
# 나이가 많을수록 소득이 높은 경향 부여
df['소득'] += df['나이'] * 40
```

CSV 없이 **난수로 표를 만드는** 패턴이다. day08에서 딕셔너리로 데이터프레임을 만들던 방법(키 = 열 이름, 값 = 열)에 넘파이 난수 함수를 값으로 끼웠다.

| 함수 | 만드는 것 | 이 표에서 |
| --- | --- | --- |
| `np.random.seed(42)` | 난수 출발점 고정 | 몇 번을 돌려도 같은 표가 나온다 — 결과를 노트와 맞춰 볼 수 있다 |
| `np.random.randint(20, 60, size=n)` | 20 이상 60 **미만** 정수 `n`개 | 나이·소득·신용점수 같은 **수치형** 열 |
| `np.random.choice(['일반', 'VIP'], size=n, p=[0.7, 0.3])` | 목록에서 뽑기, `p`로 비율 지정 | 멤버십 7:3, 이탈 여부 0.75:0.25 같은 **범주형** 열 |

`randint`의 끝이 미포함인 것은 `range`·슬라이싱과 같은 규칙이고, `choice`의 `p`는 합이 1이어야 한다. 이탈여부는 숫자 0·1이지만 뜻은 "유지/이탈" 두 가지라 **범주**로 취급한다 — 그래서 뒤에서 `hue`(색 구분) 자리에 들어간다.

마지막 줄 `df['소득'] += df['나이'] * 40`이 중요하다. 난수로만 만든 열들은 서로 아무 관계가 없어서, 상관을 보는 히트맵을 그려도 전부 0 근처로 밋밋하게 나온다. 그래서 **나이가 한 살 많을수록 소득이 40 늘어나는 경향을 일부러 심어** 두었다. 열끼리의 연산(`Series + Series`)과 복합 대입이 day08의 열 수정 문법 그대로다. 이 한 줄 덕분에 1-5의 히트맵에서 나이·소득 칸만 뚜렷한 색이 된다.

### 1-3. 카운트플롯 — 범주별 개수 세기

```python
# sns.countplot( data=데이터프레임 , x = "범주형", hue="그룹컬럼명", palette="색상테마")
sns.countplot(data=df, x="멤버십", hue="이탈여부", palette="Set1")
plt.title('멤버십별 이탈빈도')
plt.show()
```

`countplot`은 **범주 하나당 행이 몇 개인지** 세어 막대로 세운다. 지난 시간 `plt.bar(classes, counts)`는 개수를 미리 세어 `counts` 리스트로 넘겨야 했는데, 시본은 `x="멤버십"`만 주면 `value_counts()`에 해당하는 집계를 안에서 해 준다 — y를 주지 않는 이유가 그것이다.

| 인자 | 뜻 |
| --- | --- |
| `data=df` | 재료가 되는 데이터프레임. 이후 인자는 전부 **열 이름 문자열**로 적는다 |
| `x="멤버십"` | 가로축에 올릴 범주형 열. 일반·VIP 두 묶음이 생긴다 |
| `hue="이탈여부"` | 각 묶음을 **색으로 한 번 더 쪼갠다**. 일반 안에서 0·1, VIP 안에서 0·1 → 막대 네 개 |
| `palette="Set1"` | `hue` 값마다 어떤 색을 줄지 정하는 색상표 이름 |

`hue`가 시본 문법의 핵심이다. 맷플롯립이라면 그룹마다 `plt.bar`를 따로 부르고 위치를 어긋나게 계산해야 할 일을, 열 이름 하나로 끝낸다. 범례도 `hue` 열 이름과 값으로 자동 생성되어 `plt.legend()`를 부르지 않아도 붙는다. 제목은 시본 함수에 없어서 `plt.title`을 그대로 쓰고, 창을 띄우는 것도 여전히 `plt.show()`다 — **시본이 그리고 맷플롯립이 보여 주는** 구조라 두 라이브러리가 섞여 쓰인다.

### 1-4. 박스플롯 — 범주별 수치 분포 요약

```python
# 2] 박스플롯(범주형 수치 분포)
# sns.boxplot( data=데이터프레임, x="범주형컬럼명", y="수치형컬럼명", hue="그룹컬럼명")
sns.boxplot(data=df, x="멤버십", y="소득", hue="이탈여부", palette="Pastel2")
plt.title("멤버십 이탈 여부에 따른 소득 분포")
plt.show()
```

카운트플롯과 호출 모양은 같고 `y="소득"`이 하나 늘었다. x가 범주, y가 수치 — "**범주별로 수치가 어떻게 퍼져 있나**"를 보는 그림이다. 지난 노트 3-6에서 키워드로만 적어 둔 `boxplot`을 실제로 그린 셈인데, 맷플롯립의 `plt.boxplot(배열)`과 달리 그룹 나누기까지 열 이름으로 한다.

상자 하나를 읽는 법은 이렇다.

| 요소 | 뜻 |
| --- | --- |
| 상자 아래 변 | 1사분위수(Q1, 하위 25%) |
| 상자 안 가로선 | **중앙값**(Q2, 50%) |
| 상자 위 변 | 3사분위수(Q3, 상위 25%) |
| 상자 높이 | 사분위 범위 IQR = Q3 − Q1. 가운데 절반이 얼마나 모여 있나 |
| 위아래 수염 | IQR의 1.5배 안에 들어오는 최솟값·최댓값까지 |
| 수염 밖 점 | **이상치**(outlier) 후보 |

day07 따릉이 실습에서 정렬본의 `int(n * 0.9)` 위치값으로 손으로 자르던 분위수가, 여기서는 상자의 위아래 변으로 그대로 보인다. 평균 하나로 뭉개지는 치우침(평균 13,290 vs 중앙값 9,957 같은 차이)이 상자의 비대칭으로 드러나고, 멤버십 × 이탈여부 네 상자를 나란히 두면 "VIP 이탈자의 소득이 더 높은가" 같은 질문을 눈으로 비교할 수 있다. 히스토그램이 한 그룹의 모양 전체라면, 박스플롯은 **여러 그룹을 한 축에서 비교**하는 데 유리하다.

### 1-5. 히트맵 — 상관계수 행렬을 색으로

```python
# 3] 히트맵
# 상관계수 : 하나의 변수의 값이 변하면 다른 변수의 값은 증가/감소 관계 수치(-1(음) +1(양))화
numeric_df = df[ ['나이', '소득', '신용점수'] ]   # 문자열(범주형) 제외한 수치형만 추출
corr_matrix = numeric_df.corr()                   # 상관계수 행렬 계산
# 1) 히트맵 sns.heatmap( 상관계수행렬 , cmap="색상명", fmt='.소수점f' , annot=True )
sns.heatmap(corr_matrix, cmap="coolwarm", fmt='.2f', annot=True)
plt.show()
```

세 단계다. **수치 열만 고른다 → `corr()`로 상관계수 행렬을 만든다 → 그 행렬을 `heatmap`에 넘긴다.**

수업 주석의 정의를 그대로 옮기면 상관계수는 "하나의 변수의 값이 변하면 다른 변수의 값은 증가/감소 관계를 −1(음)~+1(양)로 수치화"한 것이다. 지난 노트 3-5의 `np.corrcoef`와 같은 값인데, 판다스에서는 `df.corr()` 한 번으로 **모든 열 쌍**을 한꺼번에 계산해 정사각 표를 돌려준다. 대각선은 자기 자신과의 상관이라 항상 1.00이고, 표는 대각선을 기준으로 대칭이다.

`df[ ['나이', '소득', '신용점수'] ]`로 먼저 추리는 이유는 상관계수가 **숫자끼리만** 계산되기 때문이다. 멤버십 같은 문자열 열이 섞여 있으면 오류가 나므로 이중 대괄호(day08의 열 여러 개 고르기)로 수치 열만 새 표에 담는다. 이탈여부는 숫자 0·1이라 계산은 되지만 뜻이 범주라서 함께 뺐다. 주석의 "0.85 이상"은 **강한 상관**으로 볼 만한 기준선을 적어 둔 것이다 — 모델에 넣을 때 그만큼 닮은 열 둘을 함께 쓰면 중복이라는 신호가 된다.

| 인자 | 뜻 |
| --- | --- |
| 첫 인자 `corr_matrix` | 색칠할 2차원 표. 값이 클수록 진하게 |
| `cmap="coolwarm"` | 색상표(colormap). 음수는 파랑, 0은 흰색, 양수는 빨강으로 **양쪽으로 갈라지는** 팔레트라 상관계수와 잘 맞는다 |
| `annot=True` | 칸마다 숫자를 적는다 |
| `fmt='.2f'` | 그 숫자의 서식. f-문자열의 `:.2f`와 같은 문법 — 소수점 둘째 자리 |

1-2에서 심어 둔 `+= 나이 * 40` 덕분에 나이·소득 칸만 뚜렷한 빨강으로 뜨고, 신용점수는 난수 그대로라 다른 열과 0 근처의 옅은 색이다. 색 막대(colorbar)가 오른쪽에 자동으로 붙어 색과 숫자의 대응을 보여 준다.

### 1-6. 산점도 — 두 수치 열의 관계를 점으로

```python
# 4] 산점도
# sns.scatterplot( data=데이터프레임 , x="수치컬럼명", y="수치컬럼명", hue="그룹")
sns.scatterplot(data=df, x='나이', y='소득', hue='이탈여부')
plt.title(" 나이 vs 소득 산점도 ")
plt.show()
```

히트맵이 "어느 열끼리 같이 움직이나"를 숫자 하나로 요약했다면, 산점도는 그중 **한 쌍을 골라 점으로 펼쳐** 보는 그림이다. `x`·`y`에 수치 열 두 개를 넣으면 고객 한 명이 점 하나가 되고, 1-2에서 `+= 나이 * 40`으로 심어 둔 경향이 오른쪽 위로 올라가는 띠 모양으로 그대로 드러난다. 히트맵의 0.85 근처 빨간 칸이 실제로는 어떤 모양의 관계인지 확인하는 자리라고 보면 된다.

지난 노트의 `plt.scatter(x, y, color=…)`와 그리는 결과는 같다. 다른 점은 호출 모양이다. 맷플롯립은 `x`·`y`에 **배열 두 개**를 직접 넘기고 그룹별로 색을 다르게 하려면 데이터를 미리 잘라 두 번 불러야 했는데, 시본은 `data=df`에 **열 이름**만 적고 `hue='이탈여부'`로 그룹 열을 하나 더 지정하면 색 구분과 범례가 자동으로 붙는다. 카운트플롯·박스플롯과 완전히 같은 호출 방식이라 이 시간의 네 함수가 전부 한 가족이라는 점이 여기서 분명해진다.

| 인자 | 뜻 |
| --- | --- |
| `data=df` | 열 이름을 꺼낼 데이터프레임 |
| `x='나이'`, `y='소득'` | 가로·세로 축에 둘 **수치** 열. 둘 다 숫자여야 점의 위치가 정해진다 |
| `hue='이탈여부'` | 점 색을 가를 그룹 열. 0·1처럼 값이 몇 개뿐인 수치 열도 범주처럼 색이 나뉜다 |

`hue`에 넣은 이탈여부가 숫자 0·1이라서 시본은 이를 **연속값**으로도 해석할 수 있다 — 그러면 범례가 두 색 대신 색 띠(그라데이션)로 나오기도 한다. 범주로 확실히 다루고 싶으면 `hue=df['이탈여부'].astype(str)`처럼 문자열로 바꿔 넘기거나 `palette=` 로 색을 명시하는 편이 안전하다. 또 점이 100개를 넘어 겹치기 시작하면 `alpha=0.6` 같은 투명도를 함께 주는 것이 지난 노트의 `plt.scatter` 때와 같은 요령이다.

### 1-7. 네 그림 한눈에 — 질문이 그림을 고른다

| 그림 | 함수 | x | y | 답하는 질문 | 맷플롯립이라면 |
| --- | --- | --- | --- | --- | --- |
| 카운트플롯 | `sns.countplot` | 범주 | (없음, 자동 집계) | 범주마다 **몇 개**인가 | `value_counts()` 세고 `plt.bar` |
| 박스플롯 | `sns.boxplot` | 범주 | 수치 | 범주마다 수치가 **어떻게 퍼져** 있나 | 그룹별로 잘라 `plt.boxplot` |
| 히트맵 | `sns.heatmap` | 행렬 통째 | — | 열끼리 **얼마나 같이 움직이나** | `plt.imshow` + 숫자 직접 적기 |
| 산점도 | `sns.scatterplot` | 수치 | 수치 | 두 열이 **어떤 모양으로** 함께 움직이나 | `plt.scatter(x, y)` 배열 직접 넘기기 |

공통점은 **`data=df` + 열 이름**이고, 히트맵을 뺀 셋은 `hue`로 그룹을 한 번 더 가른다. 지난 시간 네 차트가 "재료의 모양이 차트를 고른다"였다면, 이번에는 "**어느 열이 범주고 어느 열이 수치인가**"가 함수를 고른다 — 범주 하나면 카운트, 범주+수치면 박스, 수치 여러 개의 요약이면 히트맵, 수치 두 개를 자세히 보려면 산점도.

## 2. 추가로 알면 좋은 활용법

### 2-1. 박스플롯 위에 점을 겹치기 — `stripplot`·`swarmplot`

```python
sns.boxplot(data=df, x="멤버십", y="소득", color="lightgray")
sns.stripplot(data=df, x="멤버십", y="소득", hue="이탈여부", alpha=0.6, jitter=True)
plt.show()
```

시본 함수를 연달아 부르면 **같은 도화지에 겹쳐** 그려진다(지난 노트 2-4의 `plt.figure()` 규칙과 같다). 상자는 요약이라 표본 수가 적을 때 과장될 수 있는데, 그 위에 `stripplot`(점을 좌우로 조금 흔들어 찍기)이나 `swarmplot`(겹치지 않게 벌려 찍기)으로 실제 점을 올리면 상자가 몇 개의 점으로 만들어졌는지 같이 보인다. `violinplot`은 상자 대신 분포의 모양 자체를 좌우 대칭으로 그린다.

### 2-2. 히트맵 다듬기 — 범위 고정·반쪽만·크기

```python
mask = np.triu(np.ones_like(corr_matrix, dtype=bool))   # 위쪽 삼각형 가리기
plt.figure(figsize=(6, 5))
sns.heatmap(corr_matrix, mask=mask, cmap="coolwarm", vmin=-1, vmax=1,
            annot=True, fmt='.2f', square=True, linewidths=0.5)
plt.show()
```

| 인자 | 하는 일 |
| --- | --- |
| `vmin=-1, vmax=1` | 색 범위를 −1~1로 **고정**. 안 주면 표 안의 최솟값·최댓값에 맞춰 늘어나서 0.3이 새빨갛게 보일 수 있다 |
| `mask=` | `True`인 칸을 비운다. 대칭 행렬이라 위쪽 삼각형은 중복이므로 `np.triu`로 가리는 관용구 |
| `square=True` | 칸을 정사각형으로 |
| `linewidths=0.5` | 칸 사이 흰 선 |
| `center=0` | 색의 가운데를 0에 맞춤(`coolwarm` 같은 양쪽 팔레트에서) |

`corr()`에 `method='spearman'`을 주면 순위 기반 상관으로, 직선이 아닌 단조 관계도 잡힌다. 열이 많을 때는 `corr_matrix['이탈여부'].sort_values()`처럼 **목표 열 하나와의 상관만** 뽑아 보는 편이 빠르다.

### 2-3. 카운트플롯을 비율로 — `value_counts(normalize=True)`

```python
ratio = df.groupby('멤버십')['이탈여부'].mean()      # 그룹별 이탈 비율 (0·1의 평균 = 1의 비율)
sns.barplot(x=ratio.index, y=ratio.values)
```

카운트플롯은 개수라서 일반 회원이 VIP보다 많으면 막대가 당연히 높다. "어느 쪽이 **더 잘 이탈하나**"가 질문이라면 개수가 아니라 비율을 봐야 하고, 0·1 열의 평균이 곧 1의 비율이라는 점을 쓰면 `groupby().mean()` 한 줄로 나온다. 미리 집계한 값을 그릴 때는 `countplot`이 아니라 **`barplot`**(x·y를 직접 주는 막대)이다. `barplot`에 원본 `df`와 `y="이탈여부"`를 바로 주면 그룹 평균과 신뢰구간 막대를 시본이 알아서 계산해 주기도 한다.

### 2-4. 여러 그림 한 장에 — `subplots`와 `ax=`

```python
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
sns.countplot(data=df, x="멤버십", hue="이탈여부", ax=axes[0])
sns.boxplot(data=df, x="멤버십", y="소득", hue="이탈여부", ax=axes[1])
sns.heatmap(corr_matrix, annot=True, fmt='.2f', cmap="coolwarm", ax=axes[2])
plt.tight_layout()
plt.show()
```

시본 함수는 거의 전부 `ax=` 인자를 받는다. 지난 노트 3-1·3-2의 객체지향 방식(`fig, ax = plt.subplots`)과 바로 이어져서, 칸을 만들어 두고 각 칸에 시본 그림을 꽂는 식이다. `show()`를 세 번 부르던 것이 한 번으로 줄고, 세 그림을 나란히 비교할 수 있다.

### 2-5. 팔레트 고르기 — 범주용·순서용·양쪽용

| 종류 | 예 | 어울리는 자리 |
| --- | --- | --- |
| 범주형(qualitative) | `Set1`·`Set2`·`Pastel2`·`tab10` | `hue`가 멤버십·이탈여부처럼 **순서 없는** 범주일 때 |
| 순차형(sequential) | `Blues`·`viridis`·`YlGnBu` | 값이 0에서 커지는 한 방향(개수·금액) |
| 발산형(diverging) | `coolwarm`·`RdBu`·`vlag` | 0을 가운데 두고 음·양으로 갈리는 값 — **상관계수** |

수업에서 카운트플롯·박스플롯에 `Set1`·`Pastel2`(범주형)를, 히트맵에 `coolwarm`(발산형)을 쓴 것이 바로 이 구분이다. 색 이름은 맷플롯립과 공유하므로 `plt.cm`의 colormap 이름이 그대로 통한다. `sns.color_palette("Set1")`로 색 목록을 미리 볼 수 있다.

### 2-6. 수치 열만 자동으로 고르기 — `select_dtypes`

```python
numeric_df = df.select_dtypes(include='number')
corr_matrix = numeric_df.corr(numeric_only=True)
```

열 이름을 손으로 적는 대신 `select_dtypes(include='number')`로 숫자 자료형 열만 골라낼 수 있다. 열이 수십 개인 실제 데이터에서 유용하고, `corr(numeric_only=True)`도 같은 효과다. 다만 이탈여부처럼 **숫자지만 뜻은 범주**인 열은 자동 선택에 같이 딸려오므로, 빼고 싶으면 `drop(columns=['이탈여부'])`를 한 번 더 둔다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 시본의 두 층 — axes-level과 figure-level

이번에 쓴 `countplot`·`boxplot`·`heatmap`은 **axes-level** 함수다. 축(ax) 하나에 그리고, `ax=`로 자리를 지정할 수 있다. 그 위에 `catplot`·`relplot`·`displot` 같은 **figure-level** 함수가 있는데, `kind="box"`·`kind="count"`처럼 종류를 인자로 고르고 `col="멤버십"`을 주면 범주 값마다 **그림을 자동으로 나눠** 격자로 배치한다. 한 그림에 `hue`로 담기엔 범주가 많을 때 다음 단계로 쓰는 도구다.

### 3-2. 긴 형식 데이터 — 시본이 좋아하는 표 모양

시본이 `x="열", y="열", hue="열"`로 일하는 전제는 **행 하나 = 관측 하나**, 열 하나 = 변수 하나인 "긴 형식(long/tidy)"이다. 이번 `df`가 딱 그 모양이라 아무 가공 없이 들어갔다. 반대로 월별 열이 옆으로 늘어선 "넓은 형식" 표(따릉이의 1~12월 같은)는 `pd.melt`로 세로로 녹여야 `hue="월"`처럼 쓸 수 있다. `pivot`·`melt`가 판다스 다음 단계의 핵심 키워드인 이유다.

### 3-3. 상관 → 다음 단계

상관계수 행렬은 **탐색적 데이터 분석(EDA)**의 표준 첫 그림이다. 다음에 할 일은 보통 셋 중 하나다. 서로 0.85 이상인 열 둘 중 하나를 빼서 중복을 줄이거나(다중공선성), 목표 열(이탈여부)과 상관이 큰 열을 입력 후보로 고르거나, `sns.pairplot(df, hue="이탈여부")`로 모든 수치 열 쌍의 산점도를 한 번에 펼쳐 **직선이 아닌 관계**까지 눈으로 확인하는 것이다. 상관이 높다고 원인이 되는 것은 아니라는 지난 노트의 주의는 여기서도 그대로다.

### 3-4. 이상치를 숫자로 — IQR 규칙

박스플롯의 수염 밖 점은 `Q1 − 1.5·IQR` 아래, `Q3 + 1.5·IQR` 위의 값이다. `df['소득'].quantile([0.25, 0.75])`로 두 분위수를 구해 같은 식을 쓰면 **이상치 행을 코드로 골라낼** 수 있다. day08의 `clip(lower, upper)`에 넣을 경계값을 눈대중이 아니라 이 규칙으로 정하는 것이 전처리에서 흔한 연결이다.
