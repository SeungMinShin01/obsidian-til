### 1. 언어 모델의 기본 흐름

```
텍스트 → 토큰화 → 임베딩(벡터) → 트랜스포머 → 다음 토큰 확률 → 샘플링 → 텍스트
```

- **토큰** — 단어보다 작은 단위. "안녕하세요"가 2~3개 토큰으로 쪼개집니다
- **임베딩** — 토큰을 수백~수천 차원의 숫자 벡터로 변환. 의미가 비슷한 단어는 벡터도 가깝습니다
- **어텐션** — 문장 안에서 어떤 단어가 어떤 단어를 참조할지 가중치를 계산
- **다음 토큰 예측** — LLM은 본질적으로 "다음에 올 토큰의 확률 분포"를 계산하는 함수입니다

### 2. 학습 단계

1. **사전 학습(Pre-training)** — 대량의 텍스트로 다음 토큰 예측을 반복 학습
2. **지도 미세조정(SFT)** — 사람이 만든 질문-답변 쌍으로 대화 능력 부여
3. **RLHF / RLAIF** — 사람(또는 AI)의 선호를 반영해 응답 품질을 조정

### 3. 실무에서 알아둘 개념

| 용어 | 의미 |
|---|---|
| 컨텍스트 윈도우 | 한 번에 볼 수 있는 토큰 수의 한계 |
| 환각(Hallucination) | 그럴듯하지만 사실이 아닌 생성 |
| RAG | 외부 문서를 검색해 근거로 제공하는 방식 |
| 파인튜닝 | 특정 도메인에 맞게 추가 학습 |
| 프롬프트 엔지니어링 | 입력을 설계해 출력 품질을 높이는 기법 |

### 4. 개발자 관점의 활용

- 코드 생성·리뷰 — Copilot, Claude Code
- 문서 요약·번역
- 자연어 → SQL / 정규식 변환
- RPA와 결합 — 규칙 기반 자동화에 판단 능력 추가
