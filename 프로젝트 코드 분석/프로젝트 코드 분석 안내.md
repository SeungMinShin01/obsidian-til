# 프로젝트 코드 분석

이전에 진행한 **실제 프로젝트 코드**를 분석한 기록이 모이는 곳입니다.

상위: [[Vault 홈]]

## 이 폴더의 기록 방식

학습노트와 다릅니다. **개발자 일지 형식**으로 씁니다.

| | 학습노트 (언어 폴더) | 프로젝트 분석 (이 폴더) |
| --- | --- | --- |
| 목적 | 개념을 익히고 남기기 | 코드를 파악한 과정을 남기기 |
| 구성 | 배운 내용 → 활용법 → 심화 | 목표 → 살펴본 것 → 판단·근거 → 막힌 것 |
| 시점 | 주제 중심 | **날짜 중심, 시간순** |
| 남기는 것 | 정리된 결론 | **결론 + 그 판단에 이른 근거와 시행착오** |

템플릿: `_템플릿/프로젝트 분석 템플릿.md`

## 파일 이름

프로젝트마다 폴더를 하나 만들고 그 안에 문서를 둡니다.

```
프로젝트 코드 분석/
└── <프로젝트명>/
    ├── <프로젝트명> 전체 구조와 설계 분석.md    ← 주 문서
    ├── <프로젝트명>에서 배울 것.md              ← 학습 관점
    └── YYYY-MM-DD <세션 제목>.md               ← 이후 추가 분석 세션
```

주 문서는 계속 갱신하고, 새로 파고든 세션은 날짜를 붙여 따로 남깁니다.

## 분석을 요청할 때

프로젝트 폴더를 연결해 주시면 다음 순서로 진행합니다.

1. 저장소 전체 훑기 — 구조·기술스택·진입점 파악
2. 핵심 파일부터 정독
3. 데이터 흐름 추적
4. 일지 작성 — 판단 근거와 막힌 지점 포함
