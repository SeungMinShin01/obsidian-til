# 코드실습 안내

코드훈련 세션의 실습 미션 결과를 모으는 폴더다. 미션 1건 = 노트 1개.

- 파일명: `코드실습 - <미션명>.md`
- 노트 구성: `## 코드 원문` (사용자가 직접 짠 코드, 오류 포함 있는 그대로) + `## 고치면 좋은 점` (근거는 사용한 코드정리 노트명과 함께)
- frontmatter: `출처: 내가 작성` · `작성일` · `tags: [학습, <영역>]`
- 링크: 각 노트에서 사용한 `코드정리/` 노트로 **단방향**으로만 건다 (실습 → 레퍼런스). 코드정리 쪽에서 역방향 링크 금지
- 실습 목록은 이 안내 노트에 나열한다 (쌓이면 트리화 재검토)
