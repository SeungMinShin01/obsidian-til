# 수집기 17 - SPA를 만났을 때

> 허브: [[수집기 프로젝트 MOC]]

로켓펀치 목록 페이지를 열어보고 **HTML에 공고가 없다**는 것을 확인한 데서 나온 기록이다.

## 1. 배운 내용

### 1-1. 페이지를 받았는데 내용이 없다

목록 페이지를 가져왔더니 검색 필터와 정렬 UI는 있는데 **정작 공고 항목이 없었다.**

서버가 껍데기만 보내고, 브라우저가 자바스크립트를 실행해서 그때 API를 호출해 채워넣는 구조다. 이런 방식을 **SPA(Single Page Application)**라고 한다.

### 1-2. 두 방식의 차이

| | 서버 렌더 | SPA |
| --- | --- | --- |
| 첫 응답에 담긴 것 | 완성된 HTML | 빈 껍데기 + 자바스크립트 |
| 내용이 채워지는 시점 | 서버에서 | **브라우저에서** |
| `curl`로 받으면 | 내용이 보인다 | 안 보인다 |

`urllib`이나 `requests`는 자바스크립트를 실행하지 않는다. **브라우저가 아니라 파일 다운로더**이기 때문이다.

### 1-3. 확인은 열어보는 것뿐이다

로켓펀치를 「서버 렌더 HTML」이라고 판단했다가 틀렸다. 근거 없이 추정한 것이었다.

**SPA인지 아닌지는 명세서에도 `robots.txt`에도 안 적혀 있다.** 한 번 가져와서 안을 보는 것이 유일한 확인 방법이고, 그게 「수집기 13 - 소스를 쓸 수 있는지 확인하는 순서」에 「한 번 호출해본다」를 넣은 이유와 같다.

여기에 한 줄이 더 붙는다.

> **응답이 200이어도 원하는 내용이 들어 있는지는 별개다.**

「수집기 03 - Actions 실행과 트리거 설계」의 「초록불이 의도한 결과를 뜻하지 않는다」와 같은 종류의 함정이다.

### 1-4. 두 갈래

| | 내부 API 호출 | 헤드리스 브라우저 |
| --- | --- | --- |
| 받는 것 | JSON | 렌더된 HTML |
| 파싱 | 딕셔너리로 바로 | 파싱 필요 |
| **Actions 비용** | 가볍다 | **브라우저 설치·실행으로 매번 1분 이상** |
| 깨지는 조건 | 응답 형식 변경 | 화면 구조 변경 |
| 성격 | 문서화되지 않은 인터페이스 | 사람이 보는 것과 동일 |

### 1-5. 비용이 판단을 갈랐다

「수집기 16 - 수집 빈도와 깊이」에서 계산한 예산이 여기 걸린다. 하루 5회 도는데 매번 브라우저를 띄우면 **설치와 실행만으로 예산의 상당 부분이 날아간다.**

내부 API 쪽이 압도적으로 싸고 파싱도 쉽다. 대신 문서화되지 않은 인터페이스를 쓰는 것이라 예고 없이 바뀔 수 있고, 이건 어댑터 격리로 대응한다.

### 1-6. SPA가 오히려 쉬울 수도 있다

HTML 파싱은 태그 구조를 훑어야 하고, 디자인이 조금만 바뀌어도 선택자가 어긋난다. **JSON은 이름으로 꺼내므로 화면이 바뀌어도 영향받지 않는다.**

`store.upsert_jobs`가 이미 `list[dict]`를 받으므로 변환 계층도 얇아진다.

SPA를 만난 것이 나쁜 소식만은 아니다.

## 2. 추가로 알면 좋은 활용법

### 2-1. 내부 API를 찾는 방법

브라우저 개발자 도구의 Network 탭을 열고 페이지를 새로고침하면, 화면을 채우는 요청이 목록에 나타난다. 응답이 JSON인 것을 찾으면 그것이 내부 API다.

여기서 확인할 것들이 있다.

- 인증 헤더가 필요한가 — 필요하면 로그인 영역이므로 건드리지 않는다
- 페이지네이션 파라미터가 무엇인가
- 응답에 개인정보 필드가 섞여 있는가 — 있으면 저장 단계에서 버린다

### 2-2. 문서화되지 않은 인터페이스라는 것

공개 페이지가 실제로 쓰는 통로이고 인증도 없지만, **제공처가 쓰라고 만든 것은 아니다.** 명세가 없으므로 예고 없이 바뀌고, 바뀌어도 공지가 없다.

이건 우회는 아니다. 차단을 뚫는 것이 아니라 공개된 응답을 그대로 받는 것이기 때문이다. 다만 **안정성을 기대할 수 없는 통로**라는 점은 분명히 알고 쓴다.

## 3. 더 나아가 알면 좋은 것

### 3-1. 다음에 볼 키워드

- SSR / CSR / 하이드레이션
- Playwright · Selenium — 헤드리스 브라우저 도구
- 브라우저 개발자 도구 Network 탭 읽는 법
- `__NEXT_DATA__` — Next.js 페이지가 HTML 안에 데이터를 심어두는 경우가 있다
- `sitemap.xml` — 목록 페이지 대신 쓸 수 있는 경우가 있다
