# RAG 챗봇 - 규칙제안 기록

> 지침서: [[CLAUDE]]

RAG 챗봇 프로젝트를 진행하면서 Vault 전체 규칙(`CLAUDE.md`, `_규칙/구역 규칙.yaml`)에 반영을 요청한 제안들을 쌓아두는 장부다.

이 연결은 `프로젝트 노트/` 고립 규칙의 승인된 예외를 따른다.

- `[[CLAUDE]]` 링크는 **프로젝트당 이 장부 하나만** 걸 수 있다
- 개별 제안서는 이 장부에만 링크한다 (`제안서 → 장부 → CLAUDE`)
- 역방향 링크는 걸지 않는다

## 상태 표기

| 상태 | 뜻 |
| --- | --- |
| 검토 요청 | 마스터 세션에 넘겼고 답을 기다리는 중 |
| 채택 | 규칙 문서에 반영됨 |
| 부분 채택 | 일부만 반영. 어느 부분이 빠졌는지 제안 노트에 기록 |
| 보류 | 지금은 결정하지 않기로 함. 재검토 조건을 남긴다 |
| 기각 | 반영하지 않기로 함. 이유를 남긴다 |

기각된 제안도 지우지 않는다.
