# 수집기 로드맵 - 장기 구상

> 상위: [[수집기 프로젝트 MOC]]

MOC의 「로드맵」이 **확정한 가까운 단계**라면, 이 노트는 그 **너머의 구상**이다. 아직 확정 아님 — 방향과 순서를 적어두는 자리다. 실제로 착수할 때 해당 항목을 MOC 로드맵 표로 승격한다. `(미정)` 표시는 될지 자체가 불확실한 것.

## 북극성은 그대로, 다만 확장을 전제한다

수집 → 분석 → 면접 재료. 여기까진 동일. 추가된 전제 하나: **이 파이프라인을 채용에만 두지 않고 "범용 수집기"로 넓힌다.** 채용은 첫 세로줄이고, 같은 골격에 논문·뉴스를 붙인다. 그래서 지금 채용용으로 짠 어댑터 패턴·격벽·2단계 수집이 곧 재사용 골격이 된다.

## 순서를 가르는 원칙 두 개

1. **수집은 일찍, 분석은 나중에.** 「수집 안 한 데이터는 영원히 못 얻는다」. 그래서 논문·뉴스도 *분석 준비가 안 됐어도 크롤링만은 먼저* 켠다. 분석·산출은 데이터가 쌓인 뒤 언제든 소급해서 할 수 있다.
2. **되돌릴 수 있으면 겪은 뒤에.** Action 세분화·TIMEOUT 대응은 미리 짜지 않고 *실제로 겪은 뒤* 정한다 → [[개념 - 되돌릴 수 있는 결정과 없는 결정]].

## 확정한 순서

네가 준 화살표 흐름에, 위 원칙 두 개를 얹어 정리한 것. "범용 수집기 이후 4·5단계" 감각은 그대로 지켰고, 대신 논문·뉴스 *수집*은 앞당겼다(분석은 뒤에 둬도 데이터는 잃지 않도록).

| # | 단계 | 전제조건 | 목적 |
| --- | --- | --- | --- |
| 0 | 현재 기반으로 며칠 축적 | — (진행 중) | 데이터가 어느 정도 쌓일 것 |
| 1 | **잡코리아 크롤러 추가** | 0이 쌓인 뒤 | 다중 크롤러 동시 구동 → 서버문제(차단·부하·429) 경험을 **러너북(트러블슈팅) 소재**로. 채용 데이터 극대화 |
| 2 | **범용 수집기로 전환** | — | 소스 종류(채용/논문/뉴스)를 나란히 꽂는 골격으로 리팩토링. 여기서 논문(예: FastEQA 관련)·AI 뉴스 크롤러를 붙여 **수집만 먼저** 시작 (원칙 1) |
| 3 | **4단계 · 시간 변화 관측** | 데이터 축적 | 채용부터. 월별/전체 비교. `stats.py` 확장. 값이 싸서 2와 병행 가능 |
| 4 | **Action 세분화** | **TIMEOUT을 실제로 겪은 뒤** (원칙 2) | 크롤러가 많아지면 채용/논문/뉴스 잡을 분리 |
| 5 | **5단계 · 면접 재료 RAG** | 채용 데이터·우대사항 축적 | 채용 세로줄을 끝까지 완성. 북극성의 마지막 조각 |
| 6 | **웹 반환 계층** | 5까지 | 아래 6-a~6-d 순서. **채용공고가 민감하면 웹 노출에서 제외** |
| 7 | (옵션) 노션 미러링 | 필요 시 | 아무 단계에서나 |

### 6단계 웹 반환 — 안쪽 순서

| # | 내용 | 비고 |
| --- | --- | --- |
| 6-a | 통계 시각화 + **검색(RAG 아님, 키워드 매칭)**으로 일치 공고 보여주기 | 가장 먼저. RAG 없이 가능 |
| 6-b | RAG 기반 데이터 분석 | 검색 위에 얹는다 |
| 6-c | **LLM 산출물** | 아래 세 갈래 |
| 6-d | 웹에서 크롤 주소 추가 | `(미정)` — 될지 불확실 |

**6-c LLM 산출물 세 갈래**

- **채용** — 이력서를 넣으면 조건에 맞는 공고 제공 + 추가로 준비하면 좋은 것들
- **논문** — 논문·문제상황을 적으면 저장된 논문 중 유사한 것 제공
- **뉴스** — 매일 저녁/아침 메일로 화제성 AI 뉴스 발송 + 검색 시 유사 뉴스 제공 + 크롤링 뉴스를 요약본으로 웹에 띄우기(내가 보기 편하게)

## 왜 이 순서인가 (한 가지 짚어둘 점)

4단계(시간 변화)는 `stats.py`에 씨앗이 있어 **값이 싸고**, 이미 쌓이는 채용 데이터에 바로 값을 준다. 그래서 원칙대로면 2와 병행하거나 살짝 앞당겨도 좋다. 다만 네 "범용 이후" 감각을 존중해 **2 다음(3번)**에 뒀다 — 순서를 바꾸고 싶으면 3을 1~2 사이로 올리면 된다. 이건 되돌릴 수 있는 결정이라 지금 확정 안 해도 된다.
