# WMS 프로젝트 MOC

이커머스 창고관리시스템(WMS)을 3주 안에 만들고 배포하는 개인 프로젝트의 허브다. 진행하면서 나눈 대화 중 **판단의 근거로 남길 만한 것**을 주제별로 정리한다.

기능을 많이 만드는 게 목표가 아니라 **성능 문제를 스스로 발견하고 해결한 기록**을 남기는 것이 최종 산출물이다. 기능은 그 기록을 만들기 위한 재료다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 목표 | 입고·재고·출고 흐름을 만들고, 더미 데이터로 Before/After 성능 개선을 숫자로 남긴다 |
| 저장소 | `WMS-Web` (Public) — 로컬 `Desktop/WMS-Web` |
| 스택 | Spring Boot 4 + React(TS) / MySQL 8.0 + Redis / Flyway |
| 구조 | 계층형 패키지, JPA 기본 + 복잡 조회는 네이티브 쿼리 |
| 배포 | AWS EC2 t3.micro (서울) + nginx. 크레딧 $100 |
| 기간 | 집중 3주. 이후 주당 몇 시간 |
| 형태 | 개인 프로젝트 (원래 팀 기준 계획에서 범위를 잘라냄) |

## 평가받는 순서

1. Before/After 측정 표 (숫자로 남은 개선 기록)
2. 동시성 제어로 재고 정합성을 지킨 방식
3. 실제 배포된 주소
4. 기능 목록 ← 가장 덜 중요하다

이 순서가 무엇을 자르고 무엇을 남길지의 기준이 된다.

## 주제 목록

표의 순서가 읽는 순서다. 파일명 앞의 번호는 배운 순서이고 바뀌지 않는다. 읽는 순서를 바꾸고 싶을 때는 파일명을 건드리지 않고 이 표의 줄 순서만 옮긴다.

| [[WMS 02 - 계층형과 도메인형 패키지 구조]] | 둘 다 현역이다, 계층형을 고른 이유, dto가 먼저 터진다, 중간에 바꾸지 않는다 |

| [[WMS 04 - 트랜잭션 격리수준과 재고 정합성]] | REPEATABLE READ와 READ COMMITTED, 격리수준만으로는 못 지킨다, 갭 락 |

| [[WMS 06 - Flyway로 스키마를 관리하는 이유]] | 변경이 코드에 남는다, `ddl-auto: validate`, 인덱스를 처음부터 넣지 않는다 |
| [[WMS 07 - 3주 범위를 잘라낸 기준]] | 시간 조건이 모든 결정을 지배했다, 바코드 스캐너는 키보드다, 순서를 지킨다 |
| [[WMS 08 - 워킹 스켈레톤과 배포 시점]] | 「배포 후 개발」은 용어가 아니다, MVP와 다르다, 경계에서 나는 실패를 먼저 만난다 |
| [[WMS 09 - 배포처를 정하기까지]] | Oracle 가입 좌절과 손절 기준, AWS 크레딧 방식, 리전을 안 바꿔 다시 만든 일 |
| [[WMS 10 - 1GB 서버에 맞춘 배포 구조]] | JAR은 아키텍처와 무관하다, nginx가 Vite 프록시를 이어받는다, 127.0.0.1 바인딩 |

WMS 노트는 세부 파생 노트(`NN-1`)를 만들지 않는다. 깊은 내용은 해당 노트 본문의 절로 담는다.

## 장부

번호를 붙이지 않고 계속 갱신하는 문서다.

| 노트 | 용도 |
| --- | --- |
| [[WMS 진행 상황]] | 지금 어디까지 왔는지의 스냅샷. 세션이 끝날 때마다 덮어쓴다 |
| [[WMS 배포 절차]] | 빈 서버에 처음부터 올리는 법. 「왜」 칸은 직접 채우고, 3주차에 이 문서만 보고 재구축해 검증한다 |

**코드 리포에는 `.md`를 두지 않는다.** VS Code의 `docs/` 자리에 있을 문서는 전부 이 장부 목록으로 온다. 번호를 붙이지 않고 MOC에서만 연결한다.

## 개념 노트

아직 없다. 같은 개념을 두 곳 이상에서 만난 뒤에 만든다.

멱등성처럼 다른 프로젝트에서 이미 개념 노트가 있는 주제를 WMS에서 다시 만나는 경우, **공유할지 따로 만들지는 그때 사용자에게 보고하고 정한다.** 규칙에 프로젝트 간 개념 노트 공유 여부가 명시돼 있지 않다.

## 일정

| 주차 | 할 일 | 체크포인트 |

| 3주차 | 더미 100만 건, Before → 인덱스 → N+1 → 캐싱, 부하 테스트, 배포, README | Before/After가 표로 정리돼 있는가 |
