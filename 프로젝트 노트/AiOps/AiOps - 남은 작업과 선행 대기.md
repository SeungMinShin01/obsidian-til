## 2-1. 결정이 필요한 것 (11/15 코드 점검에서 나옴)

| 항목 | 지금 | 문제 | 정할 것 |
|---|---|---|---|
| 관리자의 에러 내용 조회 | 관리자 현황은 개수·상태만 준다 | 시범 운영 때 관리자가 모든 팀 에러를 봐야 한다 (D-102) | ✅ 11/15 결정 D-103: 관리자 전용 조회 API(읽기 전용, 접근 기록). **AI-107, 김지환**, AI-95·96 뒤. 남은 것: 콘솔 관리자 화면 "팀 에러 보기", 공개 문서 문장 |
| local → prod 알림 누락 | 그룹 기준이 `(팀, 지문)`이고 지문에 env가 없다 | 로컬에서 먼저 본 에러가 운영에서 처음 터져도 같은 그룹이라 `#prod`에 알림이 안 간다 | 그룹 기준에 env 추가(마이그레이션) 또는 "이 env에서는 처음"일 때도 알림 |
| LLM 중복 호출 | 지금은 `explain`을 재시도만 부른다 | AI-56 2부가 붙으면 처리 스레드가 설명을 만드는 동안(최대 20초) 재시도가 같은 그룹을 집어 LLM을 두 번 부른다 (저장은 1번, 상한은 2회 차감) | 2부에서 재시도 대상을 "생긴 지 2분 넘은 그룹"으로 좁힌다 |
| 해결한 에러의 재발 | 재발해도 알림 없음 (횟수만 +1) | 고쳤다고 표시한 에러가 다시 나도 모른다 | 16단계 상태 변경(AI-97)과 함께: RESOLVED 그룹 재발 시 다시 열고 알림할지 |
| 개인 프로젝트 팀 이름 | 팀 이름은 관리자가 직접 적는다 (기수 안에서만 중복 금지). 번호 자동 부여 없음 | — | 기수를 "개인 프로젝트"로 따로 만들고 이름은 사람·프로젝트 이름으로 (제안) |
| 환경변수 이름 수집 | hello에 PC의 모든 환경변수 **이름**(값 없음)이 최대 500개 실린다 | 이름 자체가 민감하다고 볼 수도 있다 | 그대로 두고 공개 문서에 명시 / 환경변수·시스템 속성 출처는 빼기(한 줄 수정) |
| AI 설명의 위험한 조언 | 첫 실제 설명에 "`ddl-auto`를 `create`나 `update`로"가 해결 방향으로 나옴 | 로컬에서는 맞는 조언이지만 운영 DB에서는 데이터가 날아갈 수 있다. 수강생이 그대로 따라 할 수 있음 | 프롬프트에 "운영 데이터에 영향을 줄 수 있는 조치는 그 사실을 함께 적는다" 한 줄 추가할지 (env가 운영일 때만 강조할지) |
| `bootRun` Ctrl+C 안내 | Windows에서 `gradlew bootRun`을 Ctrl+C로 끄면 직전 최대 5초의 에러가 안 간다 | 팀이 "방금 에러가 왜 안 왔지"로 헤맬 수 있다 | `sample-app/README.md`와 "연결이 안 될 때" 문서(D-102)에 한 줄 |

## 2-2. 11/16 머지된 코드를 대조해서 나온 것 (PR #59·#60·#62, 조현우 AI-106 브랜치)

| 무엇 | 왜 | 누구 | 상태 |
|---|---|---|---|
| 설명 재시도가 방금 만든 그룹까지 집는다 → LLM 중복 호출 | PR #62로 `ErrorProcessor`가 새 그룹마다 `explain`을 부른다(최대 20초). 그 사이 재시도 스케줄러가 돌면 같은 그룹을 한 번 더 부른다. 저장은 `saveIfEmpty`가 막지만 호출·일일 상한은 2번 쓴다 | 승민 | ⏳ `findIdsMissingExplanation`에 "만든 지 2분 지난 그룹만" 조건 |
| 상세 API에 시안의 커밋·앱 환경이 없다 | `RecentEvent`에 커밋이 없고 `ErrorGroupDetail`에 Java·Boot 버전·앱 이름이 없다. 값은 `app_snapshot`(hello)에 있다 | 결정 필요 → 지환 | ⏳ MVP에서 화면에서 뺄지, API에 추가할지 |
| 목록 API에 "시작 실패" 표시 값이 없다 | `phase`는 상세의 `recentEvents[]`에만 있다. 목록(`ErrorGroupSummary`)에는 없다 | 결정 필요 → 지환 | ⏳ 목록에서 뺄지, 필드를 추가할지 |
| 스택에서 "우리 팀 코드" 강조 기준이 없다 | `stack`은 문자열 목록뿐이다 | 승민 (콘솔) | ⏳ `location`의 패키지 앞부분과 같은 줄을 강조 (표시용) |
| 로그인 뒤 원래 화면으로 복귀 | 조현우 `LoginNext`: `/oauth2/authorization/github?next=/경로`. 검사는 통과(같은 사이트 경로만) | 승민 (콘솔) | ⏳ 그 PR 머지 뒤 `Login.jsx`·`client.js`에 `next` 붙이기 |
