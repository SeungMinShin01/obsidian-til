# 기술정리 MOC

기술블로그를 읽고 **내가 먼저 정리한 글**을 채팅 세션에서 다듬은(부연설명·오류 교정·문단 정리) 정리본을 모으는 구역이다. 원 글쓴이의 내용을 최대한 흡수하는 것이 목적이므로 **재해석·재작성은 최소화**한다.

이 폴더는 고립 구역이다 — 링크는 폴더 안에서만, 학습노트·MOC·프로젝트와 연결하지 않는다.

## 처리 흐름

```
채팅(Claude 프로젝트 "기술정리")에서 초안 다듬기
  → 완성본 .md를 _인박스/에 저장
  → Cowork에서 "인박스 정리해줘"
  → 스킬이 frontmatter·파일명 정리 후 주제 폴더로 배치, 이 MOC 갱신
```
