# 학습 지도

Spring 다중 세션 학습의 진도표. 모든 학습·실습 세션은 시작 시 이 파일을 읽고 종료 시 갱신한다.

## 현재 위치

- 진행 방식: **안 1** — 트랙 B(부트 공식 문서) 완주 후 트랙 S(레거시)
- 다음 세션: **B01** 학습
- 기준 버전: Spring Boot 4.1.1
- 상태 값: 예정 / 학습중 / 인박스 / 배치됨
- 산출 위치: 트랙 B → `Boot/` (`Spring Boot - `) · 트랙 S → `Legacy/` (`Spring 레거시 - `) · 대조 → `Legacy/` (`Spring 대조 - `)
- 중복 처리: 같은 개념을 두 트랙에서 쓴다. `개념키`·`트랙`·`정본` 규약은 `RAG 중복 규약` 참조

## 복습 원칙

사용자는 KDT 수업으로 부트를 이미 다뤘다(`Spring/` 구역 day01~day08). **그럼에도 겹치는 모듈을 건너뛰지 않는다.** 목적이 진도가 아니라 "그때 제대로 이해했는지 확인"이기 때문이다.

겹치는 모듈에서 세션이 할 일:

1. 해당 day 노트를 **읽고** 사용자가 그때 이해한 범위를 파악한다
2. 공식 문서와 대조해 **빠진 것·잘못 이해한 것·수업에서 생략된 것**을 찾는다
3. 요약 관문을 그 지점에 집중해서 낸다 — 이미 아는 부분을 다시 설명하게 두지 않는다

> **주의**: `기술정리`는 고립 구역이다. day 노트를 **읽는 것은 되지만**, 정리본이나 이 상태 파일에서 `Spring/` 구역으로 **위키링크를 걸면 규칙 위반**이다. 참조는 본문 서술로만 한다.
