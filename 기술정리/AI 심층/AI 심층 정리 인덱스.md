| [[AI - 코딩 에이전트 하네스]] | 에이전트 | 모델을 감싸는 껍데기(계획·액션 공간·컨텍스트 관리)를 부품 단위로 측정 — 컨텍스트 관리의 이득은 대부분 '넘쳐서 죽는 것' 방지, 규칙 기반 생략은 LLM 요약 앞에, bash 잘 쓰는 모델엔 bash만. SoL-Pi는 같은 결론을 자동 탐색으로 재발견하고 토큰 44.7~49.0% 절감 |
| [[AI - KV 캐시 압축]] | 추론 최적화 | 컨텍스트에 정비례해 늘어나는 KV 캐시를 버리지 않고 줄이는 네 가지 교환 — 인코더/디코더 반 가르기(CED), 층간 KV 공유와 후보 풀 인덱싱(CSA2), 학습 단계부터의 FP4, 영구 저장을 재계산으로 되사는 SWA Replay. 토큰당 890바이트(계기: DeepSeek-V4.1-Flash) |
| [[AI - 도메인 불문 세계 모델]] | 세계 모델 | 분야마다 새로 설계하던 세계 모델을 하나의 원리로 — JEPA의 잠재 타깃 한 덩어리를 직교 예측 분해(OPF)로 쪼개 전담 경로에 맡겼다 재결합. 시각·생물·임상·제어·분자·물리장·기상 7개 분야, Interventional Pong 오차 34.8%↓, 케플러 지수 -1.4991 복원, 지목한 생물학적 개입이 오가노이드·마우스까지 검증 (계기: JEPA-Anything) |
| [[AI - 비생성 의사결정 모델]] | 추론 구조 | 텍스트를 생성하지 않고 선택지별 보정 확률만 forward pass 한 번으로 — 상태와 질문들을 한 시퀀스에 packing하고 block-causal 마스크로 질문끼리 격리, pointer head가 선택지를 점수화(디코딩 없음). SFT+permutation KL·ordinal loss, 0.5B+LoRA가 38MB·M5에서 1h45m·6질문 160ms, ECE를 정확도와 함께 보고. 한계는 선택지 20개 초과 붕괴와 학습 분포 밖의 과신(크메르어 정확도 0%·확신 95.2%) (계기: Kev / Jev / Laya) |
| [[AI - 코딩 벤치마크 오염 측정]] | 벤치마크 | SWE-bench 점수가 추론인지 기억인지 — 실행 동작은 보존하고 단서만 지우는 4단계 변형(문제 서술 재구성·네임스페이스 재매핑·파일 내 재정렬·코드 재작성)으로 친숙도를 제거하자 성능이 일관되게 떨어지고 상호작용 비용이 늘었다. 특히 무너진 구간이 저장소 탐색과 버그 위치 특정 — 사내 코드베이스에서 에이전트가 먼저 무너지는 지점과 같다. 저하 폭 수치는 초록에 없음 (계기: SchrodingerRepo) |
| [[AI - 트랜스포머의 선형 중첩]] | 모델 내부 | 두 텍스트의 입력을 선형 결합해 넣으면 출력도 두 다음-토큰 분포의 중첩으로 나온다 — 학습이 아니라 트랜스포머 구조에서 오는 성질이고, 사전학습이 진행될수록 오히려 약해지며, 경량 파인튜닝으로 상당 부분 복원된다. 이를 이용해 한 번의 순전파로 두 문장을 동시에 생성하는 guided decoding. 초록에 정량 수치·모델 규모·파인튜닝의 성능 대가가 없고, 세 갈래 이상에서의 붕괴 지점도 미확인 (계기: HF 9/25 ▲55) |
| [[AI - 에이전트 운영체제]] | 에이전트 보안 | 에이전트의 보안 장치를 애플리케이션 미들웨어에서 커널 층으로 — 감시자가 감시 대상과 같은 프로세스 신뢰 경계를 공유하면 우회 가능하므로, 신원·입력 중재·기억·실행을 우회 불가능한 커널 서비스로. 네 기둥(Identity 위임 사슬을 자료구조로 / Perception 단일 필터를 단계적 여과로 / Cognition 기억에 정보 흐름 제어 → 오염 제한 + 검색 충실도 향상 / Execution 의미에서 커널로, 경계가 단단하면 권한을 넓힐 수 있다). 실무 판정 기준은 "프롬프트로 부탁한 것은 보안 장치가 아니다". 한계: 구현·벤치마크 전무한 입장 논문이고, 커널이 "이 문장이 지시인가 데이터인가"를 결정론적으로 어떻게 판정하는지가 미검증 — 그 판정에 또 모델을 쓰면 비판했던 구조로 되돌아온다 (계기: AgentKernel, HF ▲5) |
