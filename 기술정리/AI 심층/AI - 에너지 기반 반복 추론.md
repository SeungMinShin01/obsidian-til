# AI - 에너지 기반 반복 추론

> 상위: [[AI 심층 정리 인덱스]]

> [!info] 예습자료 — 무인 세션이 자동 생성, 사용자 미검증 · 계기: Chen·Gladstone·Li·Ji·Du 「Energy-Based Reasoners: Your Recurrent Reasoner Should Be an Energy-Based Model」(arXiv 2611.08977), HN 297점, 11/19 브리핑. 읽은 것: 프로젝트 페이지(초록·수식 네 줄·결과표 두 개·그림 설명). **논문 PDF 본문은 읽지 못했다** — 에너지 함수의 구조, 탐색 기반 학습의 구체 절차, 투영 Π의 정의는 확인 못 했다.

## 한 줄 정의

같은 블록을 여러 번 돌려 "잠재 공간에서 생각하는" 반복 추론 모델에, **"지금 생각 상태가 문제와 얼마나 맞는가"를 재는 점수(에너지)** 를 함께 배우게 해서 — 그 점수의 기울기로 상태를 고치고, 기울기가 충분히 작아지면 멈추고, 여러 후보 중 점수가 가장 낮은 것을 고르게 하는 방식. 점수 하나가 **개선·중단·선택** 세 가지를 맡는다.

## 왜 이게 문제였나 — 기존 방식의 한계

**반복(looped) 모델이란.** 보통 신경망은 층을 쌓아 깊이를 만든다. 반복 모델은 **같은 블록 하나를 여러 번 돌려** 깊이를 만든다. 스도쿠라면 "판의 잠재 표현 z"를 블록에 넣고, 나온 z를 다시 넣고… 를 반복하며 점점 답에 가까워진다. 파라미터는 블록 하나분이라 작고, 돌리는 횟수를 늘리면 더 오래 "생각"할 수 있다. 2025~2026년의 TRM·HRM 계열 작은 반복 모델들이 스도쿠·미로 같은 퍼즐에서 큰 LLM보다 잘한다는 결과로 주목받았다(결과표의 TRM·EqR·FPRM·GRAM·Looped flows가 그 비교 대상).

**빠진 것 — 진행을 재는 자.** 기존 반복 모델은 상태를 갱신할 뿐, **그 상태가 얼마나 좋은지 명시적으로 평가하지 않는다**. 그래서:

| 질문 | 기존의 답 | 문제 |
| --- | --- | --- |
| 언제 멈추나? | 고정 횟수 | 쉬운 문제에도 어려운 문제만큼 돈다 → 연산 낭비 |
| 지금 상태를 어떻게 고치나? | 학습된 전이 함수가 "알아서" | 왜 그 방향인지 해석 불가 |
| 여러 번 돌린 답 중 무엇을 고르나? | 다수결·외부 검증기 | 검증기를 따로 만들어야 하거나 샘플을 많이 뽑아야 함(EqR은 128개) |

이건 LLM 에이전트에서 지난 며칠 노트가 계속 마주친 문제와 같은 모양이다 — 성공한 실행이 정답 뒤에도 35~60% 단계를 더 돌고(Termination Lag, 11/18), 원인을 찾은 모델이 25분간 수정을 미루며(Kernel의 Carbon 분석, 11/19), 실패한 실행은 "자신 있는 최종 답"으로 끝난다(FrontierHarness, 11/18). **"내가 지금 얼마나 왔는지"를 재는 내부 신호가 없다** 는 것.

## 어떻게 푸는가

**비유 — 공과 골짜기.** 문제 x마다 지형(에너지 지형)이 하나 있다고 하자. 지형의 높이 E(z;x)는 "상태 z가 문제 x와 얼마나 안 맞는가"다. 맞는 답일수록 낮은 골짜기. 추론은 **공을 굴려 골짜기로 내려보내는 것** 이다.

프로젝트 페이지의 네 줄을 풀면:

1. **점수(Score)** — `E_θ(z; x)` : 상태 z와 처음 판 x의 궁합. 낮을수록 좋다. 이 함수를 신경망으로 학습한다
2. **개선(Refine)** — `z_{t+1} = Π_M( z_t − α ∇_z E_θ(z_t; x) )` : 지형이 내려가는 방향(기울기의 반대)으로 한 걸음(α) 옮기고, Π_M으로 허용된 상태 집합 M 안으로 되돌린다(투영의 구체 정의는 본문 미독). 기존 반복 모델의 "학습된 전이 함수"가 **"에너지의 경사 하강"** 으로 바뀐 것
3. **중단(Stop)** — `‖∇_M E_θ(z; x)‖ < τ` : 기울기가 문턱 τ보다 작으면 = 지형이 평평하면 = 골짜기 바닥에 왔다 → 멈춘다. 쉬운 퍼즐은 몇 걸음, 어려운 퍼즐은 오래
4. **선택(Select)** — `k* = argmin_k E_θ(z^(k); x)` : 여러 번 굴려 얻은 후보 중 가장 낮은 곳을 고른다. **외부 검증기 없이** 같은 점수로

**관찰된 성질.** 스도쿠에서 정답 궤적은 **낮은 에너지·작은 기울기에 안착** 하고, 틀린 궤적은 계속 움직인다(페이지 그림 설명). 즉 "멈췄다"는 것 자체가 어느 정도 "맞았다"는 신호가 된다 — LLM 에이전트의 "끝났다는 말"과 달리 **말이 아니라 측정** 이다.

**학습 — 탐색 기반 훈련.** 에너지 함수를 정답 근처에서만 배우면, 학습 때 안 가 본 상태에서 지형이 엉망일 수 있다. 그래서 "추가 모드(다른 해)를 발견하고 더 넓은 상태 집합에서 지형 모양을 잡는" 탐색 기반 훈련을 도입했다(초록). 구체 절차는 본문 미독.

**배경 맥락(일반 지식).** 에너지 기반 모델(EBM)은 Hopfield 네트워크·LeCun의 EBM 튜토리얼 이래 오래된 아이디어이고, "몇 번 생각할지 스스로 정하기"는 ACT·PonderNet 같은 적응형 연산 연구가 따로 다뤄 왔다. EBR은 이 둘을 **하나의 점수** 로 묶은 데 의미가 있다 — 멈춤 신호를 위한 별도 헤드를 두는 대신, 개선에 쓰는 바로 그 지형의 기울기를 멈춤 신호로 쓴다.

## 결과

| 과제 | EBR(1.8M 파라미터) | 비교 |
| --- | --- | --- |
| Sudoku-Extreme 단일 샘플 | **99.4%** | Looped flows 97.9%, FPRM 94.2%, EqR 93.0%, TRM 87.4% (모두 5~10M) |
| Sudoku-Extreme 다중 샘플 | **99.9%(5개)** | EqR 99.8%(128개), PTRM 98.8%(100개) |
| Maze-Hard | 87.4% / **88.3%(5개)** | FPRM 87.0%, Looped flows 86.9%(5개) |
| N-Queens 10×10 | Pass@1 **99.5%**, 20샘플로 서로 다른 해 **92.0%** 발견 | GRAM 89.7% / 57.5% |
| 그래프 색칠 10정점 | 충돌 **0**, Cov@20 54.5% | GRAM 충돌 31.3 / 51.3% |

- **연산** — 적응형 중단이 고정 깊이 EBR 대비 FLOPs **10.9배** 절감(정확도 99.9% 유지). 그 결과 EqR의 최고 정확도에 **345배** 적은 추론 FLOPs로 도달. EqR의 최고 정확도를 **반복 7배 적게(단일 샘플)·샘플 43배 적게** 달성. 학습 연산은 "비슷한 수준"
- **여러 해** — 경사 하강에 무작위성이 있어(확률적 경사 하강처럼) 출발점에 따라 **다른 골짜기** 로 내려간다. 해가 여럿인 퍼즐에서 서로 다른 정답을 많이 찾는 이유

## 실제로 쓸 수 있나

**직접 쓸 일은 아직 없다.** 1.8M짜리 퍼즐 전용 모델이고, 코드·가중치 공개 여부는 페이지에서 확인 못 했다. 하지만 **설계 원리** 는 지금 바로 쓸 만하다.

- **"멈춤 = 측정"으로 바꾸기.** 에이전트에게 "끝났으면 말해"가 아니라, **기계가 재는 수렴 신호** 로 멈추게 한다. 코딩 에이전트라면 "테스트 실패 수"가 일종의 에너지다 — 0이 되면(바닥) 멈추고, 몇 턴째 줄지 않으면(기울기 0인데 바닥이 아님 = 지역 최소) 사람에게 넘긴다. 11/18 노트의 Claude Code 팀 규칙("세 번 고쳐도 실패하면 사람에게")이 바로 이 "평평한데 높은 곳" 감지다
- **점수 하나로 개선·선택을 같이.** 여러 후보(코드 패치 N개)를 만들 때 **같은 채점 함수** 로 고치고 고르면, 개선 기준과 선택 기준이 어긋나는 문제를 피한다
- **백엔드 비유.** 경사 하강까지 안 가도, 스도쿠의 "규칙 위반 개수"를 에너지로 두고 위반이 줄어드는 방향으로 칸을 바꾸는 **지역 탐색(min-conflicts)** 은 Java로 금방 짤 수 있다. EBR은 그 "위반 개수"를 사람이 정의하는 대신 **학습** 하고, 이산 탐색 대신 연속 공간에서 미끄러진다
- **비용 관점.** "쉬운 입력은 빨리 끝내고 어려운 입력만 오래"는 서빙 비용의 핵심이다. 오늘 Kernel 분석(쉬운 버그에도 50분)과 Neon의 4단계 추론 수준이 같은 문제를 "사람이 고르는 단계"로 푼다면, EBR은 그걸 **입력마다 모델이 정하게** 한다

## 한계와 미검증 지점

- **알고리즘 퍼즐 4종뿐.** 스도쿠·미로·N-Queens·그래프 색칠 — 정답 여부가 명확하고 제약이 국소적인 문제다. 언어 추론·코드처럼 "맞음"이 흐릿한 영역에서 에너지 지형이 잘 잡힐지는 근거가 없다(브리핑도 지적)
- **지역 최소.** 틀린 상태가 낮은 에너지에 안착하면 "멈춤 = 맞음"이 깨진다. 페이지는 "틀린 궤적은 계속 움직인다"고 했지만, 그 비율이나 틀린 채 멈추는 경우의 빈도는 본문을 봐야 안다
- **문턱 τ** — 중단 문턱을 어떻게 정했는지, 과제마다 다시 맞춰야 하는지 미확인. 10.9배 절감은 특정 τ에서의 값
- **"345배"의 기준** — 비교 대상 EqR의 최고 정확도(128샘플)에 도달하는 데 드는 추론 FLOPs 기준이다. 모든 비교 모델 대비가 아니고, TRM·GRAM 수치는 GRAM 논문에서 가져온 것(같은 조건 재실행 아님)
- **학습 비용** — "비슷한 수준"이라고만 했고, 탐색 기반 훈련의 추가 비용은 수치로 못 봤다
- **동료 평가 전 arXiv** — 결과는 3시드 평균±표준편차로 보고(스도쿠 그림 기준)
