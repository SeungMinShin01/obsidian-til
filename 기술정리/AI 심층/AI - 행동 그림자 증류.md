# AI - 행동 그림자 증류

> 상위: [[AI 심층 정리 인덱스]]

## 한 줄 정의

추가학습(post-training)은 목표 과제와 **무관한 평범한 단어 선택**에도 미세한 선호 변화("행동 그림자")를 남기고, 공개 기반 모델이 두 단어 사이에서 거의 50:50으로 망설이는 질문만 골라 교사에게 **단어 하나씩** 물으면, 그 답만으로 교사의 능력 일부를 같은 기반의 학생에게 옮길 수 있다 — Active Taskless Distillation(ATD).

계기: *Post-Training Leaves Behavioral Shadows on Unrelated Decisions* (베이징대·조지아공대·상하이테크·칭화대·Lovart AI, arXiv 2609.29233, 2026-09-24, HF 업보트 249)

## 왜 이게 문제였나 — 기존 증류의 전제

**증류(distillation)**는 큰 모델(교사)의 능력을 작은 모델(학생)에게 옮기는 기법이다. 기존 방식은 모두 교사의 속이나 과제 답을 봐야 했다.

| 방식 | 학생이 보는 것 | 필요한 접근 |
| --- | --- | --- |
| 고전 증류(Hinton 2015) | 교사의 확률 분포(logits) | 교사 내부 출력 |
| 응답 증류(WizardCoder·Magicoder 류) | 교사가 쓴 **과제 답**(코드·풀이) | 과제 예시 + 긴 출력 |
| on-policy 증류 | 학생 궤적에 대한 교사의 평가 | 교사 확률 또는 채점 |
| **ATD** | **무관한 질문에 대한 단어 하나** | 공개 기반 모델 + 교사의 1토큰 응답 |

그래서 암묵적 전제가 있었다: **"과제 답을 안 보여주고, 확률도 안 보여주고, 가중치도 안 내놓으면 학습 내용은 지켜진다."** 파인튜닝한 모델을 API로만 서비스하는 회사들의 보호 논리가 대체로 이것이다.

이 전제에 먼저 금을 낸 것이 **subliminal learning** 연구(Cloud 외, *Nature* 2026)다. 교사의 성향(예: 특정 동물 선호)이 **의미상 무관한 숫자 나열**을 통해 학생에게 옮겨갔다. 다만 그건 "성향·선호"였고, 교사 출력을 **대량으로** 써야 했다. ATD가 던진 질문은 두 가지다 — ① 무관한 결정 **하나하나**로 비공개 업데이트를 관측할 수 있나(관측 가능성) ② 그걸 배우면 **능력**이 옮겨가나(능력 전이).

## 어떻게 푸는가

### 비유: 저울이 수평인 곳에서만 무게를 잰다

기반 모델에게 "재킷과 넥타이 중 하나를 골라라" 같은 평범한 질문을 수천 개 던진다고 하자. 대부분의 질문에서 모델은 한쪽을 뚜렷하게 선호한다(90:10). 이런 질문에 교사(몰래 코딩 추가학습한 모델)를 물어봐도 답은 똑같다 — 추가학습이 남긴 미세한 변화로는 90:10을 뒤집지 못한다. **정보가 0비트다.**

그런데 기반 모델이 **50.4:49.6으로 망설이는** 질문이 있다. 저울이 거의 수평인 자리다. 여기서는 아주 작은 무게(추가학습의 흔적)만 얹혀도 저울이 기운다. 논문의 실제 예시: 기반 모델은 `tie`를 아주 약간 더 선호(q=0.5044)했는데 코딩 교사는 `jacket`을 골랐다. 질문도 답도 코딩과 아무 관계가 없다.

이런 "수평 저울" 질문 수천 개의 답을 모으면, 각 답은 "추가학습이 이 방향으로 조금 밀었다"는 **1비트 관측**이 된다.

### 구조: 네 단계

1. **질문 고르기(교사를 보기 전에 고정)** — 공개 기반 모델 M₀만으로 후보 질문마다 두 단어 a, b의 상대 확률을 계산한다. `|q − 0.5| ≤ 0.02`인 질문만 남기고, 추가로 **전체 어휘 중 1위 토큰이 두 후보 중 하나**여야 한다(실제 출력 선택에서 망설이는 경우만). 질문 목록은 교사 응답을 보기 전에 확정된다 — 교사를 보며 질문을 고치면 과제 정보를 몰래 끌어오는 셈이 되기 때문
2. **교사에게 묻기** — 각 질문을 교사에게 **한 번**, 탐욕적 디코딩으로 **토큰 하나**만 받는다. 답이 두 후보 밖이면 버린다(재시도 없음)
3. **학생 학습** — 학생은 M₀과 같은 가중치에서 시작해, 남은 (질문, 단어) 쌍에 대해 **응답 토큰 하나의 교차 엔트로피**만 최소화한다
4. **평가** — 학생이 한 번도 본 적 없는 목표 과제(HumanEval+ 등)에서, **질문-답 짝을 섞어버린 대조군**과 비교한다. 대조군은 같은 단어 집합·같은 난이도 분포를 쓰되 "어느 질문에 어느 단어였나"만 뒤섞는다. 둘의 차이가 **짝이 담은 정보**다

### 왜 되는가 — 한 줄 수식을 말로

논문은 기반 모델 근처에서 1차 근사를 쓴다. 두 단어의 logit 차이 m을 가중치로 미분한 기울기 g가 있으면, 추가학습 δ 뒤의 차이는 대략 `m(θ₀) + g·δ`다. 망설이는 질문에서는 m(θ₀)이 0에 가까우므로 **g·δ의 부호(= 추가학습이 어느 쪽으로 밀었나)가 곧 답**이 된다. 질문이 수천 개면 서로 다른 g 방향 수천 개에 대해 δ의 부호를 얻는 것이고, 학생은 그 제약들을 만족하는 방향으로 움직인다. 반대로 **어떤 질문의 g와도 직교하는 δ 성분은 영영 보이지 않는다** — 그래서 옮겨지는 건 "일부"다.

### 실험 결과

**주 실험(Qwen2.5-1.5B, 교사 = rank-16 코드 DPO LoRA)** — 5,664쌍(128개 단어), 감사 결과 코드·수학·벤치마크 용어 없음. HumanEval+ pass@1: 신호 51.22 대 대조 45.88, **+5.34%p [95% CI 1.22, 9.60]**. 서로 독립적으로 다시 만든 5개 수집 × 3 시드 평균 +4.80%p.

| 학습 방식(교사=학생 동일 설정) | Δ(신호−대조) |
| --- | --- |
| LoRA r16 | +5.34 |
| LoRA r32 | +6.55 |
| LoRA r64 | +9.15 |
| Full SFT | +4.67 |

**과제별 전이(과제마다 별도 교사)** — 7개 모두 대조군보다 높았다.

| 목표 과제 | 교사가 얻은 향상 | 학생에게 옮겨진 것 |
| --- | --- | --- |
| HumanEval+ | +7.93 | +5.03 |
| ScienceQA | +14.48 | +2.53 |
| HellaSwag | +22.31 | +2.90 |
| OpenBookQA | +8.20 | +2.07 |
| CommonsenseQA | +4.75 | +1.94 |
| PIQA | +6.58 | +1.25 |
| RACE-high | +5.60 | +0.81 |

교사가 얻은 향상과 옮겨진 양이 비례하지 않는다(HellaSwag는 +22%p를 얻었는데 +2.9%p만 옮겨짐, 코드는 +7.9%p 중 +5.0%p). Qwen3-1.7B·Qwen3-4B·Llama-3.2-1B에서도 평균은 양수.

**핵심 대조 실험 세 가지**
- **능동 대 수동** — 같은 질문 예산을 망설임 필터 없는 평범한 질문에 쓰면 HumanEval+에서 능동이 +4.27%p 앞선다. 효과는 **질문 수가 아니라 질문 위치**에서 나온다
- **출처 특이성** — 코드 교사는 코드에서, 과학 교사는 과학에서 가장 크게 올린다. 두 교사 관측을 섞으면 두 기여가 모두 남는다(합성 가능). 교사 업데이트가 강할수록 그림자도 강하다
- **옮겨지지 않는 것** — HumanEval+ 정답을 **외운** 교사(+39.02%p)와 **치환 암호**를 배운 교사(≈97%p)는 전혀 옮겨지지 않았다. 외운 교사의 학생은 오히려 기반보다 낮았다

## 실제로 쓸 수 있나

**연구 도구로는 이미 쓸 만하다** — 코드 공개(github.com/myboker/ATD). 1.5B급에서 LoRA로 재현 가능한 규모다. 또 논문이 언급한 부수 효과가 흥미롭다: 학생에서 교사 방향의 변화가 **목표 과제 점수가 통계적으로 유의해지기 전에** 먼저 측정됐다. 즉 "이 모델이 몰래 무슨 추가학습을 받았나"를 감사하는 **탐지 도구**로도 쓸 수 있다는 뜻이다.

**보안 관점의 의미** — 이 결과가 흔드는 가정은 "API로만 공개하면 추가학습 내용은 안전하다"이다. 공개 기반 모델(Qwen·Llama 등) 위에 사내 데이터로 LoRA를 얹어 API로 서비스하는 구성이 흔한데, 이 구성은 정확히 ATD의 공격 전제(공개 조상 + 1토큰 블랙박스 접근)와 맞는다. 방어 쪽에서 떠올릴 수 있는 것:
- 응답에 **온도(샘플링 무작위성)**를 두면 1비트 관측에 노이즈가 섞인다(단, 논문은 탐욕적 디코딩 전제라 이 방어의 효과는 미검증)
- 짧은 단답 질문의 **대량·패턴화된 호출**을 레이트 리밋·이상 탐지로 잡는다
- 공개 기반 모델을 쓴다는 사실 자체가 공격 표면이 된다는 점을 위협 모델에 넣는다

**실무 개발자 관점에서는** 당장 쓸 기법이 아니다. 효과 크기가 작고(+1~5%p), 같은 조상을 알아야 하며, 능력을 "만드는" 게 아니라 학생이 이미 가진 잠재력을 **끌어내는** 통로이기 때문이다. 진짜 가치는 개념 쪽이다 — **출력 내용을 검열해도 출력의 선택 분포가 정보를 운반한다.** 9월 30일 뉴스 노트의 트래커 유출(내용 대신 URL·제목이 샘)과 같은 모양의 교훈이다.

## 한계와 미검증 지점

- **같은 조상 필수** — 학생이 교사와 같은 공개 기반에서 출발해야 한다. 조상이 다르거나 비공개면 망설이는 질문을 고를 수도, 1차 근사를 쓸 수도 없다. 논문은 조상이 다를 때의 실험을 내놓지 않았다
- **효과가 작고 편차가 크다** — 과제별 +0.81~+5.03%p, 주 실험 CI 하한이 1.22%p. 저자들 스스로 "모든 설정에서 신뢰할 만한 전이를 내지는 않는다"(부록 H)고 적었다
- **옮겨지는 비율이 과제마다 제각각** — HellaSwag +22%p 중 +2.9%p, 코드 +7.9%p 중 +5.0%p. 왜 어떤 능력은 그림자가 짙고 어떤 능력은 옅은지 설명이 없다
- **규모 확장 미확인** — 1~4B 모델만. 수십~수백 B 모델에서 망설이는 질문의 비율, 그림자의 선명도가 어떻게 변하는지는 모른다
- **"외운 것은 안 옮겨진다"의 해석** — 저자들은 "학생이 표현할 수 있는 능력만 옮겨진다"로 읽는다. 그러나 이 해석은 두 개의 반례(암기·암호)에서 나온 것이라, 경계가 정확히 어디인지는 열려 있다
- **1차 근사의 범위** — 추가학습이 크게 가중치를 움직였을 때(full SFT 대규모) 근사가 유지되는지 불확실. 실제로 full SFT의 Δ(+4.67)가 LoRA r64(+9.15)보다 작다
- **확장 실험은 탐색 수준** — 경계 인식 목적함수(RPM)는 CE보다 항상 낫지 않았고(OpenBookQA 예외), 다단어 관측(K=20)은 GSM8K +6.37%p 외에는 CI가 0에 닿았다
